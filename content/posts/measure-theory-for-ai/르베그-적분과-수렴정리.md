# 들어가는 말 : ∇E = E∇는 언제 정당한가?

policy gradient를 유도하는 계산은 보통 아래와 같다.


```math
J(\theta) = E_{X\sim p_\theta}[R(X)] = \int R(x)p_\theta(x)\,dx
```



```math
\nabla_\theta J(\theta) = \int R(x)\nabla_\theta p_\theta(x)\,dx
```


두 번째 줄에서 `\(\nabla_\theta\)`가 적분 기호 **안으로** 들어갔다.

보통은 이 단계가 아무 설명 없이 지나간다.

하지만 미분은 극한이므로, 방금 한 일은


```math
\boxed{ \lim\int \stackrel{?}{=} \int\lim }
```


이다.

그리고 이 교환은 **일반적으로 성립하지 않는다.**

각 점에서 `\(f_n\to 0\)`인데 `\(\int f_n=1\)`인 함수열이 실제로 존재한다. (뒤에서 설명)

즉 저 한 줄은 공짜가 아니라 **라이선스가 필요하다**.



```math
\boxed{ \text{MCT} \longrightarrow \text{Fatou} \longrightarrow \text{DCT} }
```


위 세 정리가 그 라이선스이다.

# 요약

**적분을 만드는 법** — 측도공간 `\((\Omega,\mathcal F,\mu)\)` 위에서 세 단계로 쌓아 올린다. (1절)


```math
\boxed{ \mathbf 1_A \rightarrow \text{simple} \rightarrow f\ge0 \rightarrow \text{general }f }
```


- **simple function** `\(\phi=\sum_{k=1}^m a_k\mathbf 1_{A_k}\)`: `\(\int\phi\,d\mu=\sum_k a_k\mu(A_k)\)`
- **음이 아닌 가측함수** `\(f\ge0\)`: 아래에서 근사하는 simple function들의 sup
- **일반 가측함수**: `\(f=f^+-f^-\)`로 쪼개서 뺀다. 단 `\(\infty-\infty\)`는 금지
- **`\(d\mu\)`는 무한소가 아니다**: 리만은 정의역을 쪼개 미소 길이를 더하지만, 르베그는 레벨셋의 측도를 더한다. `\(d\mu\)`는 무한소가 아니라 어느 측도로 재는지 표시하는 라벨이다 (2절)
- **따라오는 두 가지**: 측도 `\(0\)`인 예외는 적분에 보이지 않고(a.e.), `\(f\ge0\)`이면 적분값이 `\(\infty\)`여도 정의된다. `\(\infty-\infty\)`에서 막히는 것은 일반 함수뿐이다 (3절)

**극한과 적분의 교환** — 세 개의 라이선스. (4절)

| 정리    | 핵심 가정                                           | 결론                                  |
| ----- | ----------------------------------------------- | ----------------------------------- |
| MCT   | `\(0\le f_n\uparrow f\)`                            | `\(\int f_n\uparrow\int f\)`            |
| Fatou | `\(f_n\ge0\)`                                       | `\(\int\liminf f_n\le\liminf\int f_n\)` |
| DCT   | `\(f_n\to f\)` a.e., `\(\lvert f_n\rvert\le g\in L^1\)` | `\(\int f_n\to\int f\)`                 |

세 정리는  `\(\text{MCT}\to\text{Fatou}\to\text{DCT}\)`로 이어진다.

- 미분도 극한이므로, 미분과 기댓값의 교환은 수렴정리의 문제다. `\(\lvert\partial_\theta f\rvert\le g\in L^1\)`이면 DCT가 교환을 정당화한다 (7절)
- **score function estimator, policy gradient**에서도 극한과 적분 교환 라이선스가 사용된다. (8절)
- **reparameterization trick**: 3강 push-forward가 기댓값을 어느 공간에서 계산할지 바꾸고, 4강 DCT가 기댓값 안으로 미분을 넣어도 되는지를 결정한다 (9절)


이 글에서 기억할 것은 다음 문장이다.


```math
\boxed{ f_n\to f \text{라는 사실만으로} \int f_n\to\int f \text{가 되는 것은 아니다.} }
```

# 1. 적분을 만드는 법

리만 적분은 정의역을 잘게 자른다. 르베그 적분은 **치역을 자른다.**

함수값이 비슷한 점들을 한데 모아 놓고, 그 집합의 크기를 측도로 잰다.


```math
\boxed{ \text{Riemann: 정의역을 쪼갠다} \qquad \text{Lebesgue: 치역을 쪼갠다} }
```


그래서 가장 단순한 함수부터 출발할 수 있다.

**1단계 — 지시함수.**


```math
\int \mathbf 1_A\,d\mu = \mu(A)
```


측도가 원래 하던 일(집합의 크기 재기)이 적분의 특수한 경우가 된다.

**2단계 — simple function.** 유한 개의 값만 갖는 가측함수


```math
\phi = \sum_{k=1}^m a_k\mathbf 1_{A_k}, \qquad A_k\in\mathcal F
```


에 대해서는 높이 곱하기 밑면을 더하면 된다.


```math
\boxed{ \int \phi\,d\mu = \sum_{k=1}^m a_k\mu(A_k) }
```


**3단계 — 음이 아닌 가측함수.** `\(f\ge0\)`이면 `\(f\)` 아래에 들어가는 simple function을 전부 모아 그 적분의 상한을 취한다.


```math
\boxed{ \int f\,d\mu = \sup_{\substack{0\le\phi\le f\\ \phi\text{ simple}}} \int\phi\,d\mu }
```


중요한 것은 **아래에서** 근사한다는 점이다. 계단을 밑에서부터 쌓아 올려 `\(f\)`에 도달한다.

**4단계 — 일반 가측함수.** 양수부와 음수부로 쪼갠다.


```math
f=f^+-f^-, \qquad f^+=\max(f,0),\quad f^-=\max(-f,0)
```



```math
\boxed{ \int f\,d\mu = \int f^+\,d\mu-\int f^-\,d\mu }
```


단 `\(\infty-\infty\)` 꼴은 허용하지 않는다. 둘 중 적어도 하나가 유한해야 적분이 정의된다.

여기서 강조하고 싶은 것은 개별 정의가 아니라 **순서**다.


```math
\boxed{ \text{단순한 대상에서 정의하고, 극한으로 복잡한 대상까지 확장한다} }
```


이 방식은 앞으로도 여러 번 사용된다. 7강 Tonelli·Fubini의 증명 골격이 이것이고, 12강에서 Itô 적분 `\(\int H\,dB\)`를 만들 때도 똑같은 순서로 진행한다.

# 2. `\(d\mu\)`는 무한소가 아니다

1절의 정의를 다시 보면 이상한 점이 하나 있다. `\(\int f\,d\mu\)`라고 써 놓고는 정작 `\(d\mu\)`를  어디에서도 정의하지 않았다.

우리가 일반적으로 사용하는 적분에 나오는 `\(dx\)`는 미소 길이를 말한다. 하지만 `\(d\mu\)`는 미소하지 않다. `\(d\mu\)` 극한은 정의역을 잘게 쪼개는 극한이 아니라, 함수를 아래에서 밀어 올리는 극한이다.

**두 적분을 나란히 놓으면** 차이가 분명해진다.

|     | 근사합                       | 재는 대상                  | 무한소인가   |
| --- | ------------------------- | ---------------------- | ------- |
| 리만  | `\(\sum f(x_i)\,\Delta x_i\)` | `\(x_i\)` 근처 미소 구간의 **길이** | 그렇다     |
| 르베그 | `\(\sum a_k\,\mu(A_k)\)`      | `\(f\)`의 **레벨셋** `\(A_k\)`     | **아니다** |

리만은 정의역을 미소 구간으로 자르고 그 길이를 잰다. 여기서는 `\(dx\)`가 실제로 무한소의 극한이다. 구간을 잘게 만들수록 `\(\Delta x_i\to0\)`이고, 그 극한을 취하는 것이 정의의 일부다.

르베그는 다르다. `\(A_k=\{a_k\le f<a_{k+1}\}\)`은 레벨셋이다. 구간일 필요도, 작을 필요도, 연결되어 있을 필요도 없다. `\(f=\mathbf 1_{\mathbb Q}\)`라면 이 집합은 유리수 전체다. 리만 합으로는 다룰 수 없는 집합이지만, `\(\mu(\mathbb Q)=0\)`이므로 르베그 적분은 아무 문제 없이 `\(0\)`을 내놓는다.


```math
\boxed{ \text{리만: } dx\text{는 무한소 길이} \qquad \text{르베그: } d\mu\text{는 어느 측도로 재는지 표시하는 라벨} }
```


`\(\omega\)` 역시 더미 변수일 뿐이다. 그래서 다음과 같이도 쓴다.


```math
\int_\Omega f(\omega)\,d\mu(\omega) \;=\; \int f\,d\mu \;=\; \mu(f)
```


맨 오른쪽 표기가 관점을 가장 노골적으로 드러낸다. 적분은 **측도를 함수에 적용하는 연산**이다.

**이 차이가 사는 곳은 정의역이다.** 리만 적분은 정의역이 `\(\mathbb R\)`의 구간이어야 한다. “정의역을 미소 구간으로 자른다”는 말을 하려면 정의역에 순서 구조가 있어야 하기 때문이다.

르베그 적분은 그것을 쓰지 않는다. `\(\Omega\)`는 아무 집합이어도 된다. 순서도 위상도 차원도 필요 없고, `\(\sigma\)`-대수와 측도만 있으면 된다. 그래서 12강에서 브라운 운동의 경로공간 — 무한차원이고 “미소 구간”이 아무 의미도 갖지 않는 공간 — 위에서 적분을 할 수 있다. 무한소를 포기한 대가로 얻은 것이다.

**그럼 `\(d\mu=p\,dx\)`는 언제 정당한가.** `\(\mu\)`가 르베그 측도에 대해 절대연속일 때, 그리고 그때만이다. 8강 Radon–Nikodym 정리가 밀도 `\(p\)`를 주고, 그제서야 “`\(x\)` 근처 폭 `\(dx\)`의 질량 `\(\approx p(x)\,dx\)`”라는 읽기가 허용된다.

순서가 거꾸로라는 점이 중요하다. 무한소로 적분을 정의한 것이 아니라, 적분을 먼저 정의하고 나서 운이 좋은 경우에 무한소 해석이 따라붙는다. 항상 운이 좋지도 않다. 3강의 Cantor 분포는 `\(\mathrm{Leb}(C)=0\)`인 집합 위에 확률 `\(1\)`을 얹어, 연속인데도 밀도가 존재하지 않는 예시다.

# 3. a.e.와 무한대의 허용

이렇게 만들면 두 가지가 자연스럽게 따라온다.

**첫째, 측도 0인 집합은 적분에서 보이지 않는다.**

`\(f=g\)`가 거의 어디서나(almost everywhere) 성립하면


```math
\int f\,d\mu = \int g\,d\mu
```


이다. 유한 개, 심지어 가산 개의 점에서 값을 바꿔도 적분은 동일하다.


```math
\boxed{ \text{측도 0인 예외는 적분에서 보이지 않는다} }
```


그래서 르베그 적분에서는 등식이 거의 항상 a.e.를 달고 다닌다. 이는 8강(밀도가 a.e.로만 결정된다)과 11강(a.s. 수렴)에서 계속 쓰인다.

**둘째, 음이 아닌 함수의 적분은 값이 `\(\infty\)`여도 정의된다.** 3단계의 정의가 sup이기 때문이다.

함수 쪽도 마찬가지다. `\(f:\Omega\to[0,\infty]\)`처럼 값이 `\(+\infty\)`인 것까지 허용한다. `\(\{f=\infty\}=\bigcap_{k\ge1}\{f>k\}\)`이 가산교집합이라 가측성은 깨지지 않는다. 여기에 규약 하나가 따라붙는다 — `\(0\cdot\infty=0\)`이다. 측도가 `\(0\)`인 자리에서 함수값이 `\(\infty\)`로 튀어도 적분에는 기여하지 않는다는 뜻이고, 7강 Tonelli에서 다시 쓰인다.

반대 방향도 성립한다. `\(\int f\,d\mu<\infty\)`이면 `\(f<\infty\)` a.e.다. 적분이 유한하다는 것은 무한대가 측도 `\(0\)` 위에만 얹혀 있다는 뜻이다.

반면 일반 함수는 `\(\infty-\infty\)`가 되는 순간 정의 자체가 없다.

이 **음이 아닌 함수와 일반 함수의 차이**는 뒤의 강의에서도 나온다. 7강에서 Tonelli(음이 아니면 조건 없이)와 Fubini(적분가능해야)를 가르는 것이 이것이고, 8강에서 “`\(D_{\mathrm{KL}}=\infty\)`”라는 문장이 성립하는 이유도 이것이다. KL은 음이 아닌 함수의 적분이라 값이 무한대여도 말이 된다.

# 4. 세 개의 라이선스 — MCT, Fatou, DCT

이제 본론이다. 함수열 `\(f_n\)`의 극한을 `\(f\)`라 할 때


```math
\int f_n\,d\mu \quad\longrightarrow\quad \int f\,d\mu
```


가 되는가? 답은 **조건이 붙으면 된다**이고, 조건이 세 종류다. 그리고 세 조건은 극한 `\(f\)`를 어떻게 조달하는가에서 갈린다.

**단조수렴정리 (MCT).** 함수열이 밑에서부터 단조증가로 올라오면 된다.


```math
\boxed{ 0\le f_n\uparrow f \quad\Longrightarrow\quad \int f_n\,d\mu\uparrow\int f\,d\mu }
```


3단계의 정의가 애초에 “밑에서 sup”이었으므로, MCT는 정의와 결이 같다. 정의를 함수열 버전으로 옮겨 적은 것에 가깝다.

각 점에서 `\(f_n(\omega)\)`가 단조증가하면 그 수열은 `\([0,\infty]\)` 안에서 항상 수렴하므로, `\(f:=\sup_n f_n\)`으로 놓으면 `\(f_n\to f\)`는 저절로 따라온다. 값이 `\(+\infty\)`여도 괜찮다.

**Fatou 보조정리.** 단조성도 지배함수도 없고, 심지어 `\(f_n\)`이 수렴하지 않아도 된다. `\(\liminf\)`는 언제나 존재하기 때문이다. 음이 아니기만 하면, 완전한 교환은 못 해도 **한쪽 부등식**은 성립한다.


```math
\boxed{ f_n\ge0 \quad\Longrightarrow\quad \int\liminf f_n\,d\mu \le \liminf\int f_n\,d\mu }
```


부등호 방향은 이렇게 기억하면 된다. **질량은 새어 나갈 수는 있어도 없던 것이 생기지는 않는다.** 극한 쪽(왼쪽)이 더 작다.

**지배수렴정리 (DCT).** 실전에서 가장 자주 쓰는 형태다.


```math
\boxed{ f_n\to f\text{ a.e.}, \qquad \lvert f_n\rvert\le g\in L^1 \quad\Longrightarrow\quad \int f_n\to\int f }
```


모든 `\(f_n\)`을 한꺼번에 덮는 **적분가능한 천장** `\(g\)`가 하나 있으면 된다. `\(g\)`는 `\(n\)`에 의존하지 않아야 한다. 그리고 DCT만은 `\(f_n\to f\)`를 가정으로 받아야 한다 — MCT처럼 공짜로 얻지도, Fatou처럼 건너뛰지도 못한다. 가정이 유독 많아 보이는 이유가 이것이다.

세 정리는 별개의 정리가 아니라 서로 이어져 있다.


```math
\boxed{ \text{MCT} \longrightarrow \text{Fatou} \longrightarrow \text{DCT} }
```


Fatou는 `\(\inf_{k\ge n}f_k\)`가 단조증가한다는 점에서 MCT를 그대로 적용해 나오고, DCT는 지배함수를 이용해 `\(g+f_n\ge0\)`과 `\(g-f_n\ge0\)`에 Fatou를 두 번 적용하면 나온다.

> **증명은 생략한다.** 위 두 줄이 증명의 골격 전부이고 세부는 표준적이다. 여기서는 세 정리가 **하나의 사슬**이라는 사실만 가져가면 충분하다. 계산이 궁금하면 Rosenthal Ch.4를 보면 된다.

# 5. 적분과 극한이 교환되지 않는 예시

이제 앞에서 예고한 함수열을 만들자. `\([0,1]\)` 위에서


```math
\boxed{ f_n(x) = n\mathbf 1_{(0,1/n)}(x) }
```


폭이 `\(1/n\)`로 좁아지고 높이가 `\(n\)`인 직사각형이다. 넓이는 항상


```math
n\cdot\frac1n=1
```


이므로


```math
\int_0^1 f_n(x)\,dx=1
```


이다.

그런데 `\(x\)`를 하나 고정해보자. `\(x>0\)`이면 `\(n\)`이 충분히 커질 때 `\(1/n<x\)`가 되어 `\(f_n(x)=0\)`이다. `\(x=0\)`에서도 구간이 `\((0,1/n)\)`이라 항상 0이다.


```math
\boxed{ f_n(x)\to0 \qquad\forall x\in[0,1] }
```


모든 점에서 0으로 수렴하는데 적분은 항상 1이다.


```math
\boxed{ \lim\int f_n = 1 \neq 0 = \int\lim f_n }
```


이 하나의 예가 세 가지를 동시에 말해준다.

**하나, 점별수렴만으로는 적분과 극한의 교환이 보장되지 않는다.**

**둘, Fatou의 부등식은 실제로 strict할 수 있다.**


```math
\int\liminf f_n = 0 < 1 = \liminf\int f_n
```


**셋, DCT의 지배함수가 왜 필요한지 보여준다.** 모든 `\(f_n\)`을 덮는 `\(g\)`가 있다면 `\(g\)`는 `\(\sup_n f_n\)` 이상이어야 하는데, 이 값은 `\(x=0\)` 근처에서 대략 `\(1/x\)` 크기로 발산한다. 그런데


```math
\int_0^\varepsilon\frac1x\,dx=\infty
```


이므로 적분가능한 천장은 존재하지 않는다. DCT를 사용할 수 없다.

비유적으로 말하자면 다음과 같다.


```math
\boxed{ \text{질량이 각 점에서는 사라지지만 전체 질량은 사라지지 않는다} }
```


높이가 커지고 폭이 좁아지면서 질량이 `\(0\)` 근처로 **탈출**해버린 것이다.

**11강에서 마팅게일 수렴정리를 할 때 등장하는 uniform integrability(UI)가 바로 이 현상을 막는 조건이다.** DCT는 “적분가능한 천장”을 요구하는데, 이건 필요 이상으로 강하다.


```math
\boxed{ \text{DCT의 지배 조건} \;\longrightarrow\; \text{꼭 필요한 만큼 약화} \;\longrightarrow\; \text{uniform integrability} }
```

# 6. 실전에서는 어떻게?

실전에서는 정리를 외우는 것보다 **어느 것을 꺼낼지 판단하는 것**이 중요하다.

- 함수열이 단조증가하는가 `\(\longrightarrow\)` **MCT**
- 단조성도 지배함수도 없지만 음이 아닌가 `\(\longrightarrow\)` **Fatou**로 한쪽 bound
- 적분가능한 공통 천장을 찾을 수 있는가 `\(\longrightarrow\)` **DCT**

확률론과 머신러닝에서는 거의 세 번째다. 그리고 세 번째를 쓰기 위해 해야 할 일은 **지배함수 `\(g\)`를 찾는 일**이 전부다.

`\(g\)`를 찾을 때 지켜야 할 조건은 두 개뿐이다.


```math
\lvert f_n\rvert\le g \quad(\text{모든 }n\text{에 대해 같은 }g), \qquad \int g\,d\mu<\infty
```


증명시 `\(n\)`마다 다른 `\(g_n\)`을 찾는 실수를 많이 하는데 천장은 모든 `\(n\)`에 대해 하나여야 한다.

# 7. 적분 기호와 미분 — DCT가 주는 충분조건

이제 첫 문단의 질문으로 돌아간다.

미분도 극한이다.


```math
\frac{\partial}{\partial\theta}f(\theta,x) = \lim_{h\to0} \frac{f(\theta+h,x)-f(\theta,x)}{h}
```


따라서


```math
\boxed{ \frac{\partial}{\partial\theta}\int \stackrel{?}{=} \int\frac{\partial}{\partial\theta} }
```


역시 극한과 적분의 교환 문제이고, 자동으로 성립하는 공식이 아니다.

`\(F(\theta)=\int f(\theta,x)\,d\mu(x)\)`라고 두면 차분몫(difference quotient)은


```math
\frac{F(\theta_0+h)-F(\theta_0)}{h} = \int \frac{f(\theta_0+h,x)-f(\theta_0,x)}{h} \,d\mu(x)
```


이고, `\(h\to0\)`을 적분 안으로 넣고 싶다. DCT가 요구하는 것은 천장 하나다. `\(\theta_0\)` 근처의 모든 `\(\theta\)`에 대해


```math
\left| \frac{\partial f}{\partial\theta}(\theta,x) \right| \le g(x), \qquad g\in L^1(\mu)
```


인 `\(g\)`가 존재하면, 평균값 정리에 의해 차분몫도 같은 `\(g\)`가 덮으므로


```math
\boxed{ \frac{d}{d\theta} \int f(\theta,x)\,d\mu(x) = \int \frac{\partial f}{\partial\theta}(\theta,x) \,d\mu(x) }
```


가 정당화된다.

다음 문장을 기억해두자.


```math
\boxed{ \text{미분은 극한이므로, 미분과 기댓값의 교환은 수렴정리의 문제다.} }
```

# 8. score function estimator와 policy gradient

이제 다시 첫 장의 계산으로 돌아가자.


```math
J(\theta) = E_{X\sim p_\theta}[R(X)] = \int R(x)p_\theta(x)\,dx
```


문제의 그 등호,


```math
\nabla_\theta \int R(x)p_\theta(x)\,dx = \int R(x)\nabla_\theta p_\theta(x)\,dx
```


는 자동이 아니라 `\(\lvert R(x)\nabla_\theta p_\theta(x)\rvert\)`를 `\(\theta\)`에 무관하게 덮는 적분가능한 `\(g\)`가 있으면 된다.

교환이 정당화되었다고 하자. 그러면 log-derivative 항등식


```math
\nabla_\theta p_\theta(x) = p_\theta(x)\,\nabla_\theta\log p_\theta(x)
```


를 넣어


```math
\begin{aligned}
\nabla_\theta J(\theta)
&= \int R(x)\nabla_\theta p_\theta(x)\,dx \\
&= \int R(x)p_\theta(x)\,\nabla_\theta\log p_\theta(x)\,dx \\
&= E_{X\sim p_\theta}\left[ R(X)\nabla_\theta\log p_\theta(X) \right]
\end{aligned}
```


를 얻는다.


```math
\boxed{ \nabla_\theta E_{p_\theta}[R(X)] = E_{p_\theta}\left[ R(X)\nabla_\theta\log p_\theta(X) \right] }
```


이것이 **score function estimator**이고, 강화학습에서는 **REINFORCE / policy gradient**가 된다. 정책 `\(\pi_\theta\)`가 만드는 trajectory `\(\tau=(s_0,a_0,s_1,a_1,\ldots)\)`와 그 분포 `\(p_\theta(\tau)\)`에 대해 똑같은 계산을 하면


```math
\boxed{ \nabla_\theta J(\theta) = E_{\tau\sim p_\theta}\left[ R(\tau)\,\nabla_\theta\log p_\theta(\tau) \right] }
```


이다. `\(x\)`가 `\(\tau\)`로 바뀌었을 뿐 다르지 않다.

일반적인 유도 과정에 깔려 있는 것이 아래 구조다.


```math
\boxed{ \text{미분} = \text{극한} \quad\Longrightarrow\quad \text{미분과 기댓값의 교환} = \text{극한과 적분의 교환} }
```

# 9. Reparameterization trick

3강에서 reparameterization trick을 push-forward로 읽었다. `\(Z\sim N(0,1)\)`에 대해


```math
X_\theta = \mu_\theta+\sigma_\theta Z
```


로 두면 `\(X_\theta\)`의 분포는 단순한 노이즈를 함수로 밀어낸 결과다.(3강)

목적함수가


```math
J(\theta) = E_Z\left[ f(\mu_\theta+\sigma_\theta Z) \right]
```


일 때 우리는


```math
\nabla_\theta J(\theta) = E_Z\left[ \nabla_\theta f(\mu_\theta+\sigma_\theta Z) \right]
```


라고 쓴다. 또 같은 등호다.(4강)


```math
\boxed{ \nabla E = E\nabla }
```



- **3강 push-forward**: 기댓값을 **어느 공간에서 계산할 것인가**를 바꿔준다. `\(\theta\)`에 의존하는 분포 `\(p_\theta\)` 위의 적분을, `\(\theta\)`와 무관한 `\(Z\)` 위의 적분으로 옮긴다.
- **4강 DCT**: 그 기댓값 안으로 **극한이나 미분을 넣어도 되는가**를 결정한다.

# 10. 이 강의의 내용이 앞으로 쓰이는 곳

이번 글의 산출물은 두 개다. **적분이라는 기호 자체**와 **극한·적분 교환 라이선스**. 뒤 강들은 이 둘을 번갈아 꺼내 쓴다.

**A. 적분**

|강|그 강의 핵심 정의|
|---|---|
|5강|`\(E[X]=\int X\,dP\)`, `\(\lVert f\rVert_p=(\int\lvert f\rvert^p\,d\mu)^{1/p}\)`|
|8강|밀도의 뜻 `\(P(A)=\int_A \frac{dP}{d\mu}\,d\mu\)`, `\(D_{\mathrm{KL}}=\int\log\frac{dP}{dQ}\,dP\)`|
|9강|조건부 기댓값의 정의 등식 `\(\int_G E[Y\mid\mathcal G]\,dP=\int_G Y\,dP\)`|
|10강|커널 적분 `\((Kf)(x)=\int K(x,dy)f(y)\)`, 베이즈 정리의 분모 `\(\int L\,d\pi\)`|
|12강|Itô 적분 `\(\int H\,dB\)`|

**B. 수렴정리** — 뒤 강의 정리 대부분이 여기서 나온다.

- **5강 → 6강 → 9강**: `\(L^p\)`의 완비성(Riesz–Fischer)을 주는 것이 Fatou와 DCT다. 완비성 덕분에 `\(L^2\)`가 힐베르트 공간이 되고, 6강에서 사영 정리가 생기고, 9강에서 **“회귀 = 조건부 기댓값”**이라는 문장이 성립한다. 이 사슬의 출발점이 이 강이다.
- **7강**: Tonelli·Fubini의 증명 골격이 §1의 4단계를 곱공간에서 다시 돌린 것이다.
- **9강**: 조건부 MCT, 조건부 DCT, 조건부 Jensen — 이름 그대로 이 강 정리들의 조건부 버전이다.
- **11강**: 마팅게일 수렴정리, 그리고 §4의 반례를 정확히 막는 조건인 **uniform integrability**.
- **12강**: Itô 적분은 “simple에서 정의하고 극한으로 확장”이라는 §1의 레시피를 경로공간에서 다시 적용한 것이다.

**C. ML 회수선** — `\(\nabla E=E\nabla\)`는 이 글의 예제 하나가 아니라 시리즈를 관통하는 선이다.


```math
\boxed{ \text{policy gradient} \;\cdot\; \text{reparameterization} \;\cdot\; \text{score matching} \;\cdot\; \text{Fokker–Planck} }
```


특히 12강에서 만나는


```math
\frac{d}{dt}E[f(X_t)] = E[\mathcal Lf(X_t)]
```


도 결국 DCT 한 장으로 정당화되는 등식이다.

# 11. 마무리

3강에서는 가측함수로 확률을 실수축 위로 옮겼다.


```math
(\Omega,\mathcal F,P) \xrightarrow{\;X\;} (\mathbb R,\mathcal B(\mathbb R),P_X)
```


이번 글에서는 그 위의 함수를 적분하는 방법을 만들었다.


```math
\boxed{ \mathbf 1_A \longrightarrow \text{simple} \longrightarrow f\ge0 \longrightarrow f^+-f^- }
```


그리고 극한과 적분을 바꿀 수 있는 조건을 세 개 얻었다.


```math
\boxed{ \text{MCT} \longrightarrow \text{Fatou} \longrightarrow \text{DCT} }
```


기억할 것은 하나다.


```math
\boxed{ f_n\to f \text{라는 사실만으로} \int f_n\to\int f \text{가 되는 것은 아니다.} }
```


극한과 적분을 바꾸려면 이유가 필요하고, 그 이유를 제공하는 것이 수렴정리다.

이제 적분이라는 도구가 생겼다. 다음 글에서는 이것을 확률론의 언어로 번역한다.


```math
\boxed{ E[X]=\int X\,dP }
```


기댓값이 언제 존재하는지, 그리고 존재한다면 어떻게 통제되는지가 `\(L^p\)` 공간과 부등식이라는 두 도구로 정리된다.
