# 요약

```math
\boxed{
\Omega
\;\xrightarrow{\text{어떤 사건을 구별할까?}}\;
\mathcal F
\;\xrightarrow{\text{크기를 부여}}\;
\mu
}
```


- `\(\Omega\)`: 가능한 모든 결과들의 집합
- `\(\mathcal F\)`: 우리가 **관측하고 사건으로 말할 수 있는 부분집합들** = σ-대수
- `\(\mu\)`: 그 사건들의 크기
- `\(P\)`: 전체 크기가 1인 특별한 측도
- `\(\mu(N)=0\)`: null set
- 그런 예외를 무시하고 성립한다 = a.e. / a.s.

---

# 0. 표본공간 `\(\Omega\)`

확률이든 길이든 무언가를 재려면, 먼저 **무엇에 대해 재는지**가 있어야 한다.


```math
\boxed{\Omega=\text{일어날 수 있는 모든 결과들의 집합}}
```


이것을 **표본공간(sample space)** 이라고 부른다. 원소 하나 `\(\omega\in\Omega\)`는 “실제로 일어난 결과 하나”다. 일반적으로 표본점(sample point) 혹은 결과(outcome)이라고 부른다.

- 동전을 두 번 던진다: `\(\Omega=\{HH,HT,TH,TT\}\)`
- 주사위 하나: `\(\Omega=\{1,2,3,4,5,6\}\)`
- 길이를 잰다: `\(\Omega=\mathbb R\)`
- 동전을 무한히 던진다: `\(\Omega=\{H,T\}^{\mathbb N}\)`

그리고 우리가 **사건(event)** 이라고 부르고 싶은 것은 결국 `\(\Omega\)`의 부분집합이다. 정확히는 부분집합 **전부**가 아니라 그중 σ-대수 `\(\mathcal F\)`에 속하는 것만 사건이 되는데, 왜 전부일 수 없는지는 바로 다음 절에서, σ-대수의 정의 자체는 1장에서 다룬다.

> “첫 번째가 앞면이다” `\(=\{HH,HT\}\)`
> “눈이 짝수다” `\(=\{2,4,6\}\)`

결과는 원소, 사건은 부분집합. 

---

## 왜 부분집합 전부를 사건으로 쓰면 안 되는가

> `\(\Omega\)`의 **모든** 부분집합을 사건으로 인정하고, 그 전부에 크기(확률/길이)를 주면 되지 않나?

즉 멱집합 `\(\mathcal P(\Omega)\)` 전체를 크기(길이) 함수의 정의역으로 삼자는 것.

**`\(\Omega\)`가 유한하면 그래도 된다.** 동전 두 번이면 부분집합이 `\(2^4=16\)`개뿐이고, 각 결과에 `\(1/4\)`씩 주고 더하면 끝이야. (1장 예 2에서 다시 나온다.)

**문제는 `\(\Omega=\mathbb R\)`에서 문제가 생긴다.** “길이”라는 이름값을 하려면 함수 `\(\lambda\)`에게 최소한 이 세 가지는 요구해야 해.


```math
\begin{aligned}
&\text{①}\quad \lambda([a,b])=b-a
&&\text{구간은 길이 그대로}\\[2mm]
&\text{②}\quad \lambda(A+x)=\lambda(A)
&&\text{평행이동해도 그대로}\\[2mm]
&\text{③}\quad \lambda\Big(\bigsqcup_n A_n\Big)=\sum_n\lambda(A_n)
&&\text{안 겹치면 따로 재서 더해도 된다}
\end{aligned}
```


셋 다 도저히 포기할 수 없어 보이는데, 결론은 이렇다.


```math
\boxed{
\text{①②③을 모두 만족하면서 }\mathcal P(\mathbb R)\text{ 전체에서 정의되는 }\lambda\text{는 존재하지 않는다.}
}
```


Vitali 집합이라는 반례로 증명되는데,여기서는 결론만 받아들이고 가자.

그럼 선택지는 둘뿐. 

1. ①②③ 중 하나를 포기한다
2. **정의역을 줄인다** — 모든 부분집합이 아니라, 잴 수 있는 것만 골라서 잰다

측도론은 2번을 택했고 이로 인해. **σ-대수가 등장한다**

---

### 그런데 아무렇게나 줄이면 안 된다

사건으로 인정할 부분집합들의 모음을 `\(\mathcal F\)`라고 하자. 최소한 이 정도는 성립해야 말이 된다.

- “무언가는 일어났다”는 당연히 사건이다 `\(\Rightarrow\ \Omega\in\mathcal F\)`
- `\(A\)`를 사건이라고 말할 수 있으면 “`\(A\)`가 일어나지 않았다”도 말할 수 있어야 한다 `\(\Rightarrow\ A^c\in\mathcal F\)`
- `\(A_1,A_2,\dots\)`가 사건이면 “그중 적어도 하나가 일어났다”도 사건이어야 한다 `\(\Rightarrow\ \bigcup_n A_n\in\mathcal F\)`

이 세 줄이 그대로 다음 장의 σ-대수 공리다. 

---

# 1. σ-대수의 정의와 예

집합 `\(\Omega\)`가 있을 때,


```math
\mathcal F\subseteq \mathcal P(\Omega)
```


가 **σ-대수(sigma-algebra)** 라는 것은 다음을 만족한다는 뜻이야.

### 정의

**1. 전체집합이 들어간다.**


```math
\Omega\in\mathcal F
```


**2. 여집합에 대해 닫혀 있다.**


```math
A\in\mathcal F
\quad\Rightarrow\quad
A^c\in\mathcal F
```


**3. 가산(countable) 합집합에 대해 닫혀 있다.**


```math
A_1,A_2,\dots\in\mathcal F
\quad\Rightarrow\quad
\bigcup_{n=1}^{\infty}A_n\in\mathcal F.
```


따라서 자동으로


```math
\emptyset\in\mathcal F
```


이고, De Morgan 법칙에 의해 가산 교집합도 들어간다.


```math
\bigcap_{n=1}^{\infty}A_n\in\mathcal F.
```


즉 σ-대수는 **우리가 사건이라고 부를 수 있는 집합들을 모아 놓은, 논리적으로 닫힌 체계**라고 생각하면 좋아.

---

### 왜 하필 “가산” 합집합인가 

> **용어: 가산(countable)**
> **가산 = 유한 + 가산무한**이다. 가산무한(countably infinite)은 자연수 집합 `\(\mathbb N\)`과의 전단사 함수가 존재한다는 뜻, 즉 원소에 `\(1,2,3,\dots\)` 번호를 빠짐없이 매길 수 있다는 말이다.
> `\(\mathbb N,\mathbb Z,\mathbb Q\)`는 가산이고, `\(\mathbb R\)`은 비가산이다.

세 번째 조건에서 유한도 비가산도 아닌 **가산**인 것이 핵심인데, 양쪽 다 안 된다.

- **유한 합집합만 허용하면**: 극한을 다룰 수 없다. 6장의 측도의 연속성이 통째로 깨진다.
- **비가산 합집합까지 허용하면**: `\([0,1]\)`은 점들의 비가산 합집합이고 점 하나의 길이는 `\(0\)`이니, `\(\lambda([0,1])=0\)`이 돼버린다.

가산은 “극한은 다룰 수 있으면서 모순은 안 나는”  지점이야.

---


## 예 1: 자명한 σ-대수


```math
\mathcal F=\{\emptyset,\Omega\}.
```


가장 작은 σ-대수야.

이 경우 우리가 구별할 수 있는 것은

- 아무 일도 일어나지 않았다: `\(\emptyset\)`
- 무언가는 일어났다: `\(\Omega\)`

뿐이다.

정보 관점에서는 **아무 정보도 없는 상태**라고 볼 수 있어.

---

## 예 2: 멱집합


```math
\mathcal F=\mathcal P(\Omega)
```


즉 `\(\Omega\)`의 **모든 부분집합**을 사건으로 인정하는 경우야.

예를 들어


```math
\Omega=\{H,T\}
```


이면


```math
\mathcal P(\Omega)
=
\{
\emptyset,\{H\},\{T\},\{H,T\}
\}.
```


유한 집합에서는 보통 아무 문제가 없어서 멱집합을 σ-대수로 사용해도 돼.

문제는 `\(\Omega=\mathbb R\)`처럼 무한하고 거대한 공간이 되면서 생긴다.

---

## 예 3: 생성된 σ-대수

어떤 집합들의 모음


```math
\mathcal C\subseteq\mathcal P(\Omega)
```


가 주어졌다고 하자.

그러면


```math
\boxed{\sigma(\mathcal C)}
```


는 **`\(\mathcal C\)`를 포함하는 가장 작은 σ-대수**를 의미한다.

정확하게는


```math
\sigma(\mathcal C)
=
\bigcap_{\substack{
\mathcal F\text{ is a }\sigma\text{-algebra}\\
\mathcal C\subseteq\mathcal F
}}
\mathcal F.
```


즉

> “나는 최소한 `\(\mathcal C\)`에 있는 사건들은 구별하고 싶어.”

라고 요구했을 때, σ-대수의 규칙 때문에 **강제로 함께 들어와야 하는 사건들을 전부 추가한 것**이 `\(\sigma(\mathcal C)\)`야.

---

# 2. σ-대수 = 정보라는 해석

이 관점이 확률론에서 굉장히 중요해.

동전을 두 번 던졌다고 하자.


```math
\Omega=
\{HH,HT,TH,TT\}.
```


실제로 일어난 결과 `\(\omega\)`는 이 네 개 중 하나야.

---

## 상황 A: 아무것도 관측하지 않았다

σ-대수는


```math
\mathcal F_0
=
\{\emptyset,\Omega\}.
```


실제 결과가


```math
HH,\ HT,\ TH,\ TT
```


중 무엇인지 전혀 구분할 수 없어.

그래서 이것을 **가장 적은 정보**라고 본다.

---

## 상황 B: 첫 번째 동전만 관측했다

첫 번째 동전이 앞면인 사건을


```math
A=\{HH,HT\}
```


라고 하자.

관측 결과가 `\(H\)`였다면 우리는


```math
\omega\in\{HH,HT\}
```


라는 것까지만 알아.

그러면


```math
\sigma(A)
=
\{
\emptyset,
\{HH,HT\},
\{TH,TT\},
\Omega
\}.
```


왜 `\(\{HH\}\)`는 없을까?

첫 번째 동전만 봐서는 `\(HH\)`와 `\(HT\)`를 구분할 수 없기 때문이야.

그래서 σ-대수를 **“현재 정보로 구별 가능한 사건들의 모음”** 이라고 해석할 수 있다.

---

# 3. 정보가 많아진다는 것은 σ-대수가 커지는 것

두 번째 동전까지 모두 관측하면


```math
HH,HT,TH,TT
```


를 모두 구별할 수 있다.

따라서


```math
\mathcal F_2=\mathcal P(\Omega).
```


그러면


```math
\mathcal F_0
\subset
\mathcal F_1
\subset
\mathcal F_2.
```


즉


```math
\boxed{\text{정보 증가}
\quad\Longleftrightarrow\quad
\sigma\text{-대수가 커짐}}
```


이다.

이게 나중에 확률과정에서


```math
\mathcal F_0\subseteq
\mathcal F_1\subseteq
\mathcal F_2\subseteq\cdots
```


라는 **filtration**으로 발전해.

시간 `\(t\)`까지 얻은 정보를 `\(\mathcal F_t\)`라고 표현하는 거지.

---

## 재미있는 예: 정확한 결과는 모르고 앞면 개수만 안다

두 번 던졌는데 앞면의 개수 `\(X\)`만 알려준다고 하자.


```math
X(HH)=2,
```



```math
X(HT)=X(TH)=1,
```



```math
X(TT)=0.
```


그러면 우리는 `\(HT\)`와 `\(TH\)`를 구별할 수 없다.

원자(atom)는


```math
\{HH\},\quad
\{HT,TH\},\quad
\{TT\}.
```


따라서


```math
\sigma(X)
```


에는 이 세 집합의 모든 합집합이 들어간다.

총


```math
2^3=8
```


개의 사건이 생긴다.

여기서 일반적으로 확률변수 `\(X\)`가 주는 정보는


```math
\boxed{
\sigma(X)
=
\{X^{-1}(B):B\in\mathcal B(\mathbb R)\}
}
```


라고 표현한다.

즉 **σ-대수와 정보라는 해석이 그냥 비유가 아니라 수학적으로 정확한 개념**이야.

---

# 4. Borel σ-대수

이제 표본공간이


```math
\Omega=\mathbb R
```


실수라고 해보자.

가장 먼저 떠오르는 것은


```math
\mathcal P(\mathbb R)
```


에 모든 부분집합이 있으니 이것을 쓰면 되지 않느냐는 거야. 하지만 0장에서 봤듯이 `\(\mathcal P(\mathbb R)\)` 전체에는 일관되게 길이를 줄 수 없다.

그런데 우리는 보통


```math
\boxed{\mathcal B(\mathbb R)}
```


이라는 **Borel σ-대수**를 먼저 사용한다.

정의는


```math
\boxed{
\mathcal B(\mathbb R)
=
\sigma(\{\text{open sets of }\mathbb R\})
}
```


이다.(열린 집합으로 부터 생성된 시그마 대수)

동치로


```math
\mathcal B(\mathbb R)
=
\sigma\big(\{(a,b):a<b\}\big).
```


즉

> 열린구간들을 측정할 수 있다하고, σ-대수 규칙상 따라오는 모든 집합을 넣는다.

---


# 5. 측도(measure)의 공리

측정공간


```math
(\Omega,\mathcal F)
```


에 대해


```math
\mu:\mathcal F\to[0,\infty]
```


가 측도라는 것은

### ① 공집합의 크기는 0


```math
\mu(\emptyset)=0.
```


### ② 가산 가법성

서로 겹치지 않는


```math
A_i\cap A_j=\emptyset
\qquad(i\neq j)
```


에 대하여


```math
\boxed{
\mu\left(
\bigcup_{n=1}^{\infty}A_n
\right)
=
\sum_{n=1}^{\infty}\mu(A_n)
}
```


이다.

사실 측도론에서 가장 중요한 조건은 이 **countable additivity**라고 봐도 돼.

---

# 확률측도

확률측도 `\(P\)`는 그냥 측도인데 한 가지 조건이 추가된다.


```math
\boxed{P(\Omega)=1}
```


따라서


```math
(\Omega,\mathcal F,P)
```


를 **확률공간**이라고 한다.

확률론은 사실상


```math
\boxed{\text{전체 질량이 1인 측도론}}
```


이라고 볼 수 있어.

---

# 6. 측도의 연속성

이 성질은 매우 중요해. (확률론의 극한 논증을 다룰 때 중요)

## 아래에서의 연속성

집합이 점점 커진다고 하자.


```math
A_1\subseteq A_2\subseteq A_3\subseteq\cdots
```


그리고


```math
A=\bigcup_{n=1}^\infty A_n.
```


그러면


```math
\boxed{
\mu(A_n)\to\mu(A)
}
```


즉


```math
\mu\left(\bigcup_n A_n\right)
=
\lim_{n\to\infty}\mu(A_n).
```


이를


```math
A_n\uparrow A
```


라고 쓰기도 해.

---

### 예


```math
A_n=\left[0,1-\tfrac1n\right].
```


그러면


```math
A_n\uparrow[0,1)
```


이고


```math
\lambda(A_n)
=
1-\frac1n
\to1
=
\lambda([0,1)).
```


---

# 위에서의 연속성

반대로


```math
A_1\supseteq A_2\supseteq\cdots
```


이고


```math
A=\bigcap_{n=1}^{\infty}A_n
```


이라 하자.

`\(\mu(A_1)<\infty\)` 라는 조건 아래


```math
\boxed{
\mu(A_n)\to\mu(A)
}
```


이다.

즉


```math
A_n\downarrow A
```


이면


```math
\mu(A_n)\downarrow\mu(A).
```


확률측도에서는


```math
P(A_1)\le1
```


이므로 이 유한성 조건이 자동으로 만족된다.

---

### 예


```math
A_n=\left(0,\tfrac1n\right).
```


그러면


```math
A_n\downarrow\emptyset
```


이고


```math
\lambda(A_n)=\frac1n\to0.
```


이 성질 덕분에 무한한 사건도 **유한한 사건들의 극한으로 근사해서 확률을 구할 수 있다.**

---

# 7. Lebesgue 측도 — 우리가 이미 쓰고 있던 그 측도

사실 6장 연속성의 예에서 우리는 아무 설명 없이 `\(\lambda\)`를 썼다.


```math
\lambda(A_n)=1-\frac1n,
\qquad
\lambda\left(\left(0,\tfrac1n\right)\right)=\frac1n.
```


이 `\(\lambda\)`가 **Lebesgue 측도**이고, 우리가 “길이”, “넓이”, “부피”라고 부르며 아무 의심 없이 써온 바로 그것이다.

## 우리가 `\(\lambda\)`에게 요구하는 것

`\(\mathbb R\)` 위의 측도 `\(\lambda\)`에게 바라는 성질은 사실 세 개뿐이다. 0장에서 “이걸 다 만족하는 `\(\lambda\)`는 `\(\mathcal P(\mathbb R)\)` 위에 없다”고 하고 넘어갔던 바로 그 세 개인데, 이번엔 정의역을 `\(\mathcal B(\mathbb R)\)`로 줄였으니 사정이 달라진다.

**① 구간의 크기는 길이 그대로**


```math
\lambda([a,b])=b-a
```


**② 평행이동해도 크기가 변하지 않는다**


```math
\lambda(A+x)=\lambda(A)
```


**③ 가산가법성** (5장의 공리 ②)


```math
\lambda\left(\bigsqcup_{n}A_n\right)
=
\sum_n\lambda(A_n)
```


①은 “길이”라는 이름값이고, ②는 자리를 옮긴다고 길이가 변하면 안 된다는 직관이며, ③은 구간을 합쳐서 길이를 구한 것과 구간의 길이를 구하고 합친 것과 같다는 의미야 



---

## 그런데 이 `\(\lambda\)`가 존재하는가?

여기서 결정적인 질문이 나온다.

> **①②③을 모두 만족하는 `\(\lambda\)`가 정말 존재하는가?**

지금까지 우리는 측도가 무엇인지 **정의**만 했다. 정의를 만족하는 대상이 실제로 있다는 보장은 없었다.

정리하면 우리가 처한 상황은 이렇다.


```math
\boxed{
\begin{array}{ccc}
\text{크기를 아는 곳} && \text{정의해야 하는 곳}\\[2mm]
(a,b]\mapsto b-a && \mathcal B(\mathbb R)\\[2mm]
\text{단순하고 명시적} &\Longrightarrow& \text{복잡하고 묘사 불가}
\end{array}}
```


이 간극을 메워주는 것이 다음 절의 **Carathéodory 확장정리**다.

즉 Lebesgue 측도는 정의하면 그만인 대상이 아니라, 존재가 증명되어야 하는 대상이야.


---

# 8. Carathéodory 확장정리

이 절에서는 Carathéodory 확장정리를 통해 Lebesgue 측도의 **존재성**이 어떻게 보장되는지 설명한다. 정리는 statement만 도구로 쓰고 증명은 다루지 않으니, 깊은 설명이 궁금하지 않다면 바로 다음 장으로 넘어가도 무방하다.

앞 절에서 드러난 간극을 정확히 메워주는 정리다. statement에 나오는 두 단어부터 정리하고 가자.

## 준비 ①: algebra란?

**algebra(대수)** 는 σ-대수에서 **가산**합집합 조건을 **유한**합집합으로 약화시킨 것이다.


```math
\begin{aligned}
&\text{(i)}\quad \Omega\in\mathcal A\\[1mm]
&\text{(ii)}\quad A\in\mathcal A\ \Rightarrow\ A^c\in\mathcal A\\[1mm]
&\text{(iii)}\quad A,B\in\mathcal A\ \Rightarrow\ A\cup B\in\mathcal A
\end{aligned}
```


1장의 σ-대수 정의와 비교하면 (i), (ii)는 똑같고 (iii)만 다르다. σ-대수는 무한히 합쳐도 되지만 algebra는 유한 번만 허용한다.

|                      | 합집합  | 성격              |
| -------------------- | ---- | --------------- |
| algebra `\(\mathcal A\)` | 유한 개 | 원소를 손으로 적을 수 있다 |
| σ-대수 `\(\mathcal F\)`    | 가산 개 | 극한을 다룰 수 있다     |

### 예: 구간 algebra

`\(\mathbb R\)`에서 유한 개의 서로소 반열린구간의 합만 모으면


```math
\mathcal A=\left\{\ \bigsqcup_{i=1}^{n}(a_i,b_i]\ :\ n<\infty\ \right\}
```


이건 algebra지만 σ-대수는 **아니다.** 예를 들어


```math
\bigcup_{n=1}^{\infty}\left(0,1-\tfrac1n\right]=(0,1)
```


은 유한 개 반열린구간의 합으로 쓸 수 없으므로 `\(\mathcal A\)`에 들어 있지 않다.

바로 이 “유한 개만 신경 쓰면 된다”는 성질 덕분에, 우리는 algebra 위에서는 **크기를 직접 손으로 지정할 수 있다.** 

---

## 준비 ②: premeasure란?

**premeasure(예비측도)** 는 한마디로 **algebra 위에 정의된, 측도가 될 자격을 갖춘 함수**다. 조건은 측도와 똑같이 두 개다.

**①** `\(\mu_0(\emptyset)=0\)`

**②** 서로소인 `\(A_1,A_2,\dots\in\mathcal A\)`에 대하여


```math
\mu_0\left(\bigsqcup_{n=1}^{\infty}A_n\right)
=
\sum_{n=1}^{\infty}\mu_0(A_n)
\qquad
\left(\text{단, }\bigsqcup_{n}A_n\in\mathcal A\text{ 인 경우에만}\right)
```


이 단서가 핵심이다. `\(\mathcal A\)`는 가산합집합에 닫혀 있지 않으므로 `\(\bigsqcup_n A_n\)`이 `\(\mathcal A\)` 밖으로 나가버릴 수 있고, 그러면 좌변이 아예 정의되지 않는다. 그래서 ②는 “운 좋게 `\(\bigsqcup_n A_n\)`가 `\(\mathcal A\)` 안에 남아 있을 때만” 요구하는 **조건부 가산가법성**이다.

측도와 나란히 놓으면 차이가 분명해진다.

| | 정의역 | 가산가법성 |
|---|---|---|
| **premeasure** `\(\mu_0\)` | algebra `\(\mathcal A\)` | 합집합이 `\(\mathcal A\)` 안에 있을 때만 |
| **measure** `\(\mu\)` | σ-대수 `\(\mathcal F\)` | 항상 |

즉 premeasure는 **정의역이 아직 좁을 뿐, 측도가 될 자격은 이미 갖춘 함수**다. 그래서 앞에 **pre-** 가 붙는다. 확장정리는 이 자격을 진짜 측도로 승격시켜 주는 장치다.

> ⚠️ ②는 공짜가 아니다. 우리가 쓸 `\(\lambda_0((a,b])=b-a\)`가 실제로 ②를 만족한다는 사실 자체가 증명이 필요한 보조정리이고, 그 증명에는 Heine–Borel 컴팩트성이 들어간다. 유한가법성만 가지고는 확장이 되지 않는다.

---

## statement

> **정리 (Carathéodory extension theorem).**
> algebra `\(\mathcal A\)` 위에 premeasure `\(\mu_0\)`가 주어지면, 이것을 `\(\sigma(\mathcal A)\)` 위의 측도 `\(\mu\)`로 확장할 수 있다. 그리고 `\(\mu_0\)`가 σ-finite이면 그 확장은 유일하다.

식으로 쓰면


```math
\boxed{
\mu:\sigma(\mathcal A)\to[0,\infty],
\qquad
\mu|_{\mathcal A}=\mu_0
}
```


인 측도가 **존재**하고, σ-finite 조건 아래 **유일**하다.

증명은 외측도(outer measure)를 만들어서 하는데, 우리에게 필요한 건 증명이 아니라 **이 정리를 도구로 쓰는 것**이니 결론만 가져가자.

핵심적인 메시지는


```math
\boxed{
\text{단순한 집합들에 크기를 정의한다}
\Rightarrow
\text{복잡한 }\sigma\text{-대수 전체로 확장한다}
}
```


야.

> **여담: 이 정리를 우리는 이미 쓰고 있다**
> 존재성이 “Lebesgue 측도를 만들 수 있다”는 이야기라면, 유일성은 우리가 매일 무의식적으로 쓰는 쪽이다. `\(F(x)=P(X\le x)\)` 하나만 알면 `\(\mathcal B(\mathbb R)\)` 위의 분포 `\(P_X\)`가 **완전히 결정된다.**
> 구간에서만 값을 정해줬는데 모든 Borel 집합에서의 확률이 따라오는 것 

---

# 그래서 Lebesgue 측도는 이렇게 만들어진다

7장에서 원했던 그 Lebesgue 측도를 이제 실제로 만들어보자.

먼저 쉬운 구간에 대해서


```math
\lambda_0((a,b])=b-a
```


라고 정의한다.

유한 개의 서로소 구간의 합에는


```math
\lambda_0
\left(
\bigsqcup_i(a_i,b_i]
\right)
=
\sum_i(b_i-a_i)
```


라고 정의한다.

이런 단순한 집합들의 algebra에서 시작한다.

Carathéodory를 적용하면


```math
\boxed{
\text{구간의 길이}
\quad\longrightarrow\quad
\text{Borel 집합의 Lebesgue 측도}
}
```


로 확장할 수 있다.

# 무한 동전 던지기는 어떻게 가능한가?

지금까지 Carathéodory를 `\(\mathbb R\)` 위에서만 썼는데, 이 정리의 진짜 위력은 **`\(\mathbb R\)`이 아닌 공간에서도 그대로 통한다**는 데 있다.

그 대표적 예시가 **확률과정**이다.

> **용어: 확률과정(stochastic process)**
> 확률변수 하나가 아니라 `\(X_1,X_2,X_3,\dots\)` 처럼 시간 순서로 늘어선 확률변수들의 열을 말한다. 주가의 일별 변동, 강화학습 에이전트가 겪는 에피소드, 랜덤워크가 전부 여기 해당한다.


그리고 **무한 동전던지기는 확률과정 중 가장 단순한 것**이다. 

무한 번 동전을 던진다고 하자.


```math
\Omega=\{H,T\}^{\mathbb N}.
```


한 결과는


```math
\omega=(H,T,H,H,T,\dots)
```


같은 무한열이다.

처음 3번이 `\(HTH\)`인 사건을 생각하면


```math
C=
\{\omega:
\omega_1=H,
\omega_2=T,
\omega_3=H
\}.
```


이런 것을 **cylinder set**이라고 한다.

직관적으로 확률을


```math
P(C)=\frac1{2^3}
```


라고 정의한다.

일반적으로 처음 `\(n\)`번의 특정 결과를 지정하면


```math
P(C)=2^{-n}.
```


그러면 이러한 단순한 cylinder 사건들에 먼저 확률을 정의하고,


```math
\boxed{
\text{cylinder sets}
\rightarrow
\sigma(\text{cylinder sets})
}
```


로 확장한다.

그래서 **실제로 무한 번의 동전던지기를 하나의 확률공간으로 만드는 것이 가능**해진다.

좀 더 일반적인 확률과정에서는 이 아이디어가 **Kolmogorov extension theorem**으로 나타나지만 여기서는 생략

따라서 정확하게 말하면:

- Lebesgue measure의 존재 → Carathéodory extension이 직접적인 핵심
- 무한 확률과정의 존재 → cylinder set에서 시작하는 같은 확장 철학이며, 보통 Kolmogorov extension theorem으로 정리

# 9. Null set

지금부터는 **측도공간** 


```math
(\Omega,\mathcal F,\mu)
```


을 대상으로 이야기한다. 여기까지 온 김에 세 기호가 각각 무엇이었는지 한 번 정리하고 가자.

| 기호           | 이름   | 하는 일                                               |
| ------------ | ---- | -------------------------------------------------- |
| `\(\Omega\)`     | 표본공간 | 일어날 수 있는 **모든 결과**의 집합                             |
| `\(\mathcal F\)` | σ-대수 | 그중 우리가 **사건이라 부를 수 있는** 부분집합들의 모음                  |
| `\(\mu\)`        | 측도   | 각 사건에 **크기**를 매기는 함수 `\(\mu:\mathcal F\to[0,\infty]\)` |

순서대로 읽으면


```math
\boxed{
\text{무엇이 일어날 수 있나}
\;\rightarrow\;
\text{무엇을 구별할 수 있나}
\;\rightarrow\;
\text{그게 얼마나 큰가}
}
```


가 된다. 확률에서는 `\(\mu\)` 자리에 `\(P\)`를 쓰고 `\(P(\Omega)=1\)`이 붙어서 `\((\Omega,\mathcal F,P)\)`, 즉 확률공간이 된다.

앞에서 본 두 가지 예를 이 형식으로 다시 쓰면 이렇다.

| | `\(\Omega\)` | `\(\mathcal F\)` | 측도 |
|---|---|---|---|
| 동전 두 번 | `\(\{HH,HT,TH,TT\}\)` | `\(\mathcal P(\Omega)\)` | 각 결과에 `\(\tfrac14\)` |
| 실직선 | `\(\mathbb R\)` | `\(\mathcal B(\mathbb R)\)` | Lebesgue 측도 `\(\lambda\)` |

---

## 정의

이 위에서


```math
N\in\mathcal F
```


이고


```math
\boxed{\mu(N)=0}
```


이면 `\(N\)`을 **null set**이라고 한다.

조건이 두 개라는 점을 눈여겨보자.

- `\(N\in\mathcal F\)` : 애초에 **크기를 잴 수 있는 집합**이어야 한다. `\(\mathcal F\)` 밖의 집합에는 `\(\mu\)`가 값을 주지도 않으므로 “크기가 0”이라는 말 자체가 성립하지 않는다.
- `\(\mu(N)=0\)` : 그 잰 크기가 0이다.

---

### 예

유리수 전체의 집합 `\(\mathbb Q\)`가 크기를 가지고 있지 않다는 것을 보이자
Lebesgue measure에서 한 점은


```math
\lambda(\{x\})=0.
```


유한 또는 가산 개의 점도


```math
\lambda(\{x_1,x_2,\dots\})
\le
\sum_{n=1}^{\infty}\lambda(\{x_n\})
=0.
```


따라서


```math
\lambda(\mathbb Q)=0.
```


`\(\mathbb Q\)`는 무한히 많은 점을 가지고 심지어 `\(\mathbb R\)`에서 dense하지만, Lebesgue measure는 0이다.

여기서 중요한 직관은


```math
\boxed{
\text{measure zero}
\neq
\text{empty}
}
```


라는 것.

---

# 10. Almost everywhere

어떤 성질


```math
f(x)=g(x)
```


가 모든 `\(x\)`에서 성립하는 것은 아니지만, 실패하는 집합


```math
N=\{x:f(x)\neq g(x)\}
```


의 측도가


```math
\mu(N)=0
```


이라면


```math
\boxed{
f=g
\quad\mu\text{-almost everywhere}
}
```


라고 한다.

줄여서


```math
f=g\quad\text{a.e.}
```


라고 써.

즉

> **측도 0짜리 예외를 제외하면 모든 곳에서 성립한다.**

---

### 예


```math
f(x)=0
```


이고


```math
g(x)=
\begin{cases}
1,&x=0\\
0,&x\neq0
\end{cases}
```


라고 하자.

둘은 `\(x=0\)`에서 다르지만


```math
\lambda(\{0\})=0.
```


따라서


```math
f=g
\qquad\text{Lebesgue-a.e.}
```


이다.

측도론적 적분에서는 그래서 둘을 사실상 같은 함수처럼 취급한다.

예를 들어


```math
\int f\,d\lambda
=
\int g\,d\lambda.
```

# 11. Almost surely

확률측도 `\(P\)`를 사용하는 경우 a.e.를 특별히


```math
\boxed{\text{almost surely}}
```


라고 부른다.

즉 어떤 사건 `\(A\)`가


```math
P(A)=1
```


이면

> `\(A\)`는 almost surely 일어난다.

라고 한다.

기호로


```math
A\quad\text{a.s.}
```


---

## a.s.는 반드시 일어난다는 뜻이 아니다

이게 매우 중요해.


```math
\boxed{
P(A)=1
\not\Rightarrow
A=\Omega
}
```


이다.

확률 0인 결과가 여전히 존재할 수 있기 때문이야.

예를 들어


```math
X\sim U[0,1]
```


이면


```math
P(X=0.5)=0.
```


그렇다고 `\(X=0.5\)`가 논리적으로 불가능한 것은 아니다.

그래서

- **surely**: 예외 자체가 없다.
- **almost surely**: 예외는 있을 수 있지만 그 예외의 확률이 0이다.

라는 차이가 있다.

---

# 무한 동전던지기에서 더 놀라운 예

공정한 동전을 무한 번 던져


```math
\omega=(H,T,H,\dots)
```


라는 **특정한 하나의 무한열**이 나올 확률은 얼마일까?

처음 `\(n\)`개가 그 열과 일치할 확률은


```math
\frac1{2^n}.
```


사건을


```math
A_n=
\{\text{처음 }n\text{개가 지정된 열과 같다}\}
```


라고 하면


```math
A_1\supseteq A_2\supseteq\cdots
```


이고


```math
\bigcap_{n=1}^{\infty}A_n
=
\{\omega\}.
```


측도의 위에서의 연속성에 의해


```math
P(\{\omega\})
=
\lim_{n\to\infty}P(A_n)
=
\lim_{n\to\infty}\frac1{2^n}
=0.
```


즉


```math
\boxed{\text{모든 특정 무한열의 확률은 0}}
```


이다.

그런데 실제로 실험하면 **어떤 한 무한열은 나와야 한다.**

이것이


```math
\boxed{\text{확률 0} \neq \text{불가능}}
```


을 이해하는 대표적인 예야.

# 12. a.e.와 a.s.의 관계

사실 수학적으로는 똑같은 말이야.

일반적인 측도 `\(\mu\)`에 대해서는


```math
\text{almost everywhere}
```


라고 하고, 확률측도 `\(P\)`에 대해서는


```math
\text{almost surely}
```


라고 부르는 것뿐이다.

즉


```math
\boxed{
\text{a.s.}
=
\text{a.e. with respect to }P
}
```


라고 생각하면 된다.

| 표현 | 측도 | 의미 |
|---|---|---|
| a.e. | 일반 `\(\mu\)` | `\(\mu\)`-measure 0의 예외를 제외 |
| a.s. | 확률 `\(P\)` | probability 0의 예외를 제외 |

# 13. 지금까지를 한 흐름으로 연결하면



먼저 우리가 다루려는 결과 공간이 있다.


```math
\Omega.
```


하지만 모든 부분집합을 측정할 수 있는 것은 아니므로,


```math
\boxed{\mathcal F}
```


라는 σ-대수를 선택한다.

이것은
> **어떤 사건을 우리가 구별하고 이야기할 수 있는가**

를 나타낸다.

그 위에


```math
\mu:\mathcal F\to[0,\infty]
```


를 정의한다.


```math
\boxed{
(\Omega,\mathcal F,\mu)
}
```


가 측도공간이다.

특히


```math
\mu(\Omega)=1
```


이면


```math
\boxed{
(\Omega,\mathcal F,P)
}
```


가 확률공간이다.

그런데 처음부터 복잡한 모든 사건에 측도를 정의하기 어렵다.

그래서


```math
\text{intervals / cylinder sets}
```


같은 단순한 집합에 먼저 정의한 뒤,


```math
\boxed{\text{Carathéodory extension}}
```


를 통해 생성된 σ-대수까지 확장한다.

그러고 나면


```math
\mu(N)=0
```


인 집합 `\(N\)`이 생긴다.

그런 예외를 무시하여


```math
\boxed{\text{a.e.}}
```


라는 개념을 사용하고, 확률론에서는 이를


```math
\boxed{\text{a.s.}}
```


라고 부른다.

한 줄로 쓰면:


```math
\boxed{
\begin{array}{ccccc}
\Omega
&\rightarrow&
\mathcal F
&\rightarrow&
\mu\\[2mm]
\text{가능한 결과}
&&
\text{정보/사건}
&&
\text{크기}
\end{array}
}
```


그리고


```math
\boxed{
\begin{aligned}
\mathcal B(\mathbb R)
&=\text{자연스러운 실수의 사건들},\\
\text{Carathéodory}
&=\text{단순한 집합에서 복잡한 사건으로 측도 확장},\\
\mu(N)=0
&=\text{null set},\\
\text{a.e./a.s.}
&=\text{null set을 제외하고 성립}.
\end{aligned}
}
```


특히 다음 단계에서 **“σ-대수 = 정보” → random variable의 measurable함 → conditional expectation `\(E[X\mid\mathcal F]\)`** 까지 연결하면, 왜 현대 확률론이 굳이 σ-대수라는 언어를 쓰는지가 상당히 선명해진다.
