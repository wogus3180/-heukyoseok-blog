> **한 줄 요약**: `\(E[Y\mid X]\)`는 `\(P(A\mid B)=P(A\cap B)/P(B)\)` 같은 나눗셈으로 정의되는 값이 아니다. `\(X\)`가 알려 주는 정보만 사용해 `\(Y\)`를 표현하면서, 그 정보로 구별할 수 있는 모든 사건에서 평균을 보존하는 확률변수다. `\(Y\in L^2\)`라면 이것은 정확히 `\(Y\)`의 `\(L^2\)` 사영이고, 따라서 제곱손실 회귀의 이론적 최적해가 된다.

---

# 들어가는 말: `\(P(X=x)=0\)`인데 우리는 왜 `\(E[Y\mid X=x]\)`라고 쓰는가?

학부 확률론에서 조건부확률은 보통


```math
\boxed{ P(A\mid B)=\frac{P(A\cap B)}{P(B)} }
```


로 처음 배운다.

`\(P(B)>0\)`이면 아무 문제가 없다.

예를 들어 주사위를 던져


```math
B=\{\text{짝수가 나왔다}\}
```


는 정보를 얻었다고 하자.

그전에는 가능한 결과가


```math
\{1,2,3,4,5,6\}
```


이었다면, 이제는


```math
\{2,4,6\}
```


만 남는다.

즉 조건화란 직관적으로


```math
\boxed{\text{새로운 정보를 얻은 뒤 확률을 다시 계산하는 것}}
```


이다.

그런데 연속확률변수에서는 바로 문제가 생긴다.


```math
X\sim N(0,1)
```


이라고 하면 모든 `\(x\in\mathbb R\)`에 대해


```math
P(X=x)=0.
```


따라서 학부 공식으로


```math
P(Y\in A\mid X=x)
```


를 정의하려 하면


```math
\frac{P(Y\in A,\;X=x)}{P(X=x)} = \frac00
```


가 된다.

하지만 통계와 머신러닝에서는 매일같이


```math
p(y\mid x),\qquad E[Y\mid X=x]
```


를 사용한다.

무언가 다른 정의가 필요하다.

핵심은 조건화의 대상을


```math
\boxed{\text{확률 0인 사건 }\{X=x\}}
```


으로 잡는 대신


```math
\boxed{X\text{를 관측함으로써 얻는 정보 전체}}
```


로 바꾸는 것이다.

그 정보를 수학적으로 표현하는 것이 바로


```math
\boxed{\sigma(X)}
```


라는 `\(\sigma\)`-대수다.

그리고 조건부 기댓값의 기본 객체는


```math
\boxed{E[Y\mid \sigma(X)]}
```


이다.

이를 줄여서


```math
E[Y\mid X]
```


라고 쓴다.

이번 강의 핵심적인 관점 전환은 이것이다.


```math
\boxed{ \text{conditioning on an event} \quad\longrightarrow\quad \text{conditioning on information} }
```

# 요약

이번 강의의 흐름을 먼저 한 번 보자.

### 1. 확률 `\(0\)`인 사건에는 단순한 나눗셈을 사용할 수 없다


```math
P(A\mid B)=\frac{P(A\cap B)}{P(B)}
```


는 `\(P(B)>0\)`일 때만 사용할 수 있다.

특히 연속확률변수에서는


```math
P(X=x)=0
```


이므로 `\(X=x\)`에 조건화하는 문제를 다른 방식으로 정의해야 한다.

### 2. 조건화할 대상은 사건이 아니라 정보 `\(\mathcal G\)`다

부분 `\(\sigma\)`-대수


```math
\mathcal G\subseteq\mathcal F
```


를 현재 알고 있는 정보라고 생각한다.

`\(E[Y\mid\mathcal G]\)`는 이 정보만 사용해서 만들 수 있는 확률변수다.

### 3. 조건부 기댓값은 두 조건으로 정의된다

`\(Z=E[Y\mid\mathcal G]\)`라는 것은


```math
Z\text{가 }\mathcal G\text{-가측}
```


이고 모든 `\(A\in\mathcal G\)`에 대해


```math
\boxed{ \int_A Z\,dP = \int_A Y\,dP }
```


라는 뜻이다.

두 조건은 학부 조건부확률에서 이미 성립하던 성질이다. `\(\mathcal G=\sigma(B)\)`, `\(Y=1_A\)`로 두면 첫 번째 조건은 `\(B\)`와 `\(B^c\)` 위에서 각각 상수라는 것이고, 두 번째 조건은 곱셈법칙과 전확률의 법칙이다.

### 4. 존재성은 Radon–Nikodym 정리에서 나온다


```math
\nu(A)=\int_A Y\,dP,\qquad A\in\mathcal G
```


로 측도를 만들면


```math
\nu\ll P|_{\mathcal G}.
```


따라서 RN 정리에 의해


```math
\frac{d\nu}{dP|_{\mathcal G}}
```


가 존재하고, 이것이 `\(E[Y\mid\mathcal G]\)`다.

### 5. 조건부확률도 조건부 기댓값이다


```math
\boxed{ P(A\mid\mathcal G) = E[1_A\mid\mathcal G]. }
```


하지만 이것은 고정된 `\(A\)`마다 하나의 확률변수를 주는 정의다.

다음 강에서는 이를


```math
K(\omega,A)
```


라는 하나의 객체로 동시에 정리하여, 각 `\(\omega\)`마다 `\(A\mapsto K(\omega,A)\)`가 실제 확률측도가 되게 만든다.

그 객체가 확률 커널이다.

### 6. `\(L^2\)`에서는 조건부 기댓값이 직교사영이다


```math
L^2(\mathcal G) = \{Z\in L^2:Z\text{는 }\mathcal G\text{-가측}\}
```


라 하면


```math
\boxed{ E[Y\mid\mathcal G] = \operatorname{Proj}_{L^2(\mathcal G)}Y. }
```


따라서


```math
\boxed{ E[Y\mid X] = \arg\min_{f(X)} E[(Y-f(X))^2]. }
```


회귀의 이론적 target이 조건부 평균인 이유다.

# 1. 학부 조건부확률은 어디에서 문제가 되는가

조건부확률


```math
P(A\mid B) = \frac{P(A\cap B)}{P(B)}
```


는 사실 아주 좋은 정의다.

단 하나의 조건이 있다.


```math
\boxed{P(B)>0.}
```


문제는 우리가 실제로 원하는 조건화가 이 조건을 자주 만족하지 않는다는 것이다.

예를 들어


```math
X\sim \operatorname{Unif}[0,1]
```


이라 하자.

그러면


```math
P(X=1/2)=0.
```


따라서


```math
P(Y\in A\mid X=1/2)
```


를 위의 비율로 정의할 수 없다.

그렇다고


```math
X\in \left[ \frac12-\varepsilon, \frac12+\varepsilon \right]
```


에 조건화한 뒤 `\(\varepsilon\to0\)`을 보내면 되지 않을까?

충분히 좋은 상황에서는 실제로 이런 극한이 우리가 원하는 답을 줄 수 있다.

하지만 여기에는 새로운 선택이 들어갔다.

우리는 `\(X=1/2\)`이라는 집합 자체만 사용한 것이 아니라


```math
\left[ \frac12-\varepsilon, \frac12+\varepsilon \right]
```


라는 **주변의 근방을 어떤 방식으로 줄여 갈 것인가**까지 정했다.

확률 `\(0\)`인 집합에서는 이 선택이 답을 바꿀 수 있다. 같은 집합으로 줄어드는 두 근방이 서로 다른 극한을 주는 예가 실제로 있다(아래 곁가지). 따라서


```math
\boxed{ P(B)=0\text{인 집합 }B\text{ 자체만으로는 일반적으로 }P(A\mid B) \text{를 결정할 수 없다.} }
```


이제 조건화의 중심을 사건 `\(B\)`에서 **정보**로 옮길 차례다.

---

## 곁가지: 확률 0인 집합으로는 조건화가 결정되지 않는다

> 위의 결론이 어떻게 일어나는지 궁금하지 않다면 건너뛰어도 좋다. 다음 절로 넘어가는 데 지장은 없다.

위에서 근방을 줄여 가는 방식이 답을 바꿀 수 있다고 했다. 간단한 예로 확인해 보자.

### 정사각형의 대각선

`\((X,Y)\)`가 단위 정사각형 `\([0,1]^2\)` 위에서 균일하다고 하자.

묻고 싶은 것은 간단하다.

> “점이 대각선 `\(Y=X\)` 위에 있다는 조건 아래에서 `\(X\)`의 분포는 무엇인가?”

대각선은 넓이가 `\(0\)`이므로


```math
P(Y=X)=0
```


이고, 학부 공식은 `\(0/0\)`이 된다.

그래서 대각선 주변의 얇은 근방에 먼저 조건화하고, 그 두께를 `\(0\)`으로 보내 보자.

### 방법 1 — 띠로 줄이기

첫 번째 근방은 대각선을 따라 폭이 일정한 띠다.


```math
S_\varepsilon=\{|Y-X|<\varepsilon\}.
```


`\(X=x\)`에서 세로로 자르면 이 띠의 단면은


```math
x-\varepsilon<Y<x+\varepsilon
```


으로, 길이가 `\(2\varepsilon\)`인 구간이다. 모든 `\(x\)`에서 두께가 같다.

따라서


```math
P(X\in dx,\;S_\varepsilon)\approx 2\varepsilon\,dx, \qquad P(S_\varepsilon)\approx 2\varepsilon
```


이고, 둘을 나누면 조건부밀도는 `\(1\)`이다.


```math
\lim_{\varepsilon\to0}P(X\le t\mid S_\varepsilon)=t.
```


즉 띠로 줄이면 대각선 위의 조건부분포는


```math
\boxed{ X\text{의 조건부밀도}=1 \qquad (0\le x\le1) }
```


이다.

### 방법 2 — 쐐기로 줄이기

두 번째 근방은 원점에서 부채꼴로 퍼져 나가는 쐐기다.


```math
W_\varepsilon=\left\{\left|\frac YX-1\right|<\varepsilon\right\}=\{|Y-X|<\varepsilon X\}.
```


`\(X=x\)`에서 세로로 자르면 단면은


```math
(1-\varepsilon)x<Y<(1+\varepsilon)x
```


로, 길이가 `\(2\varepsilon x\)`다. 원점 근처에서는 뾰족하고 `\(x=1\)` 쪽으로 갈수록 두꺼워진다.

따라서


```math
P(X\in dx,\;W_\varepsilon)\approx 2\varepsilon x\,dx, \qquad P(W_\varepsilon)\approx\int_0^1 2\varepsilon x\,dx=\varepsilon
```


이고, 둘을 나누면 조건부밀도는 `\(2x\)`다.


```math
\lim_{\varepsilon\to0}P(X\le t\mid W_\varepsilon)=\int_0^t 2x\,dx=t^2.
```


즉 쐐기로 줄이면 대각선 위의 조건부분포는


```math
\boxed{ X\text{의 조건부밀도}=2x \qquad (0\le x\le1) }
```


이다.

정사각형의 모서리 근처에서는 띠와 쐐기가 잘려 나가지만, 그 영향은 `\(O(\varepsilon)\)`이라 극한에서 사라진다.

### 같은 집합, 다른 답

두 근방은 모두 같은 대각선으로 줄어든다.


```math
\{Y=X\}=\{Y-X=0\}=\{Y/X=1\}.
```


그런데 답이 다르다. 조건부 평균만 비교해도


```math
\lim_{\varepsilon\to0}E[X\mid S_\varepsilon]=\int_0^1x\,dx=\frac12, \qquad \lim_{\varepsilon\to0}E[X\mid W_\varepsilon]=\int_0^1x\cdot2x\,dx=\frac23.
```


차이는 근방의 두께가 대각선 위의 위치마다 다르다는 데서 나온다. 띠의 두께는 어디서나 `\(2\varepsilon\)`이지만 쐐기의 두께는 `\(2\varepsilon x\)`라서 원점 쪽 점들에 질량을 덜 준다. `\(\varepsilon\)`을 아무리 줄여도 두 점 `\(x,x'\)`에서의 두께의 비 `\(x:x'\)`는 그대로 남는다.

조건화하는 집합 `\(B\)`의 확률이 양수였다면 이런 일은 일어나지 않는다. 근방 `\(U_\varepsilon\)`이 `\(B\)`로 줄어들 때 측도의 연속성에 의해


```math
\frac{P(A\cap U_\varepsilon)}{P(U_\varepsilon)} \longrightarrow \frac{P(A\cap B)}{P(B)}
```


이므로 근방의 모양은 극한에 영향을 주지 못한다. `\(P(B)=0\)`이면 분자와 분모가 모두 `\(0\)`으로 가고, 둘이 `\(0\)`으로 가는 **속도의 비**가 답이 된다. 그 속도를 정하는 것이 근방의 모양이다.

이 현상은 **Borel–Kolmogorov 역설**이라는 이름으로 알려져 있다. 조건부 기댓값을 정의한 뒤 11절에서 이 역설을 다시 풀어 본다.

# 2. `\(\sigma\)`-대수는 정보다

2강에서 `\(\sigma\)`-대수를

> 현재 정보로 구별 가능한 사건들의 모음

이라고 해석했다.

이 해석이 조건부 기댓값에서 본격적으로 작동한다.

확률공간


```math
(\Omega,\mathcal F,P)
```


가 있고


```math
\mathcal G\subseteq\mathcal F
```


가 부분 `\(\sigma\)`-대수라고 하자.

`\(\mathcal F\)`가 세상의 모든 정보를 담고 있다면, `\(\mathcal G\)`는 현재 우리가 알고 있는 정보만 담고 있다고 생각할 수 있다.

가장 극단적인 두 경우를 보자.

### 아무 정보도 없는 경우


```math
\mathcal G = \{\varnothing,\Omega\}.
```


이 `\(\sigma\)`-대수에 들어 있는 사건은 절대 일어나지 않는 `\(\varnothing\)`과 반드시 일어나는 `\(\Omega\)`뿐이다.

둘 다 실험 결과를 보기 전부터 답을 아는 사건이다.

즉 결과를 보고 나서도 새로 알게 되는 것이 없다.

이 정보만 사용해서 만들 수 있는 실수값 확률변수, 곧 `\(\mathcal G\)`-가측인 확률변수는 상수뿐이다.

`\(Z\)`가 두 점 `\(\omega,\omega'\)`에서 서로 다른 값 `\(a\ne b\)`를 가진다고 해 보자. `\(Z\)`가 `\(\mathcal G\)`-가측이라면 사건 `\(\{Z=a\}\)`는 `\(\mathcal G\)`에 속해야 한다. 그런데 이 사건은 `\(\omega\)`는 품고 `\(\omega'\)`는 품지 않으므로 `\(\varnothing\)`도 `\(\Omega\)`도 아니다.

그래서 이런 `\(Z\)`는 a.s.로 상수인 정도가 아니라 모든 점에서 상수다.

아무것도 모르는 상태에서 내놓을 수 있는 답은 `\(\omega\)`와 상관없는 숫자 하나뿐이라는 뜻이다.

### 모든 정보를 아는 경우

반대로


```math
\mathcal G=\mathcal F
```


라면 `\(\mathcal F\)`에 속하는 사건을 모두 구별할 수 있다.

확률변수 `\(Y\)`는 `\(\mathcal F\)`-가측이므로 모든 Borel 집합 `\(D\)`에 대해 `\(\{Y\in D\}\in\mathcal F\)`다.

이 사건들이 일어났는지를 모두 알면 `\(Y\)`의 값 자체를 알게 된다.

### 그 사이

실제로 우리가 가진 정보는 대개 이 두 극단 사이에 있다.


```math
\boxed{ \{\varnothing,\Omega\} \subseteq \mathcal G \subseteq \mathcal F }
```


`\(\mathcal G\)`가 클수록 구별할 수 있는 사건이 많아지고, 그 정보만으로 만들 수 있는 확률변수도 많아진다.

정보가 이렇게 늘어날 때 조건부확률이 어떻게 달라지는지, 3절에서 주사위로 직접 계산해 보자.

---

# 3. 학부 조건부확률을 정보의 언어로 다시 읽기

`\(\sigma\)`-대수를 정보로 보는 관점이 실제로 어떻게 작동하는지, 이미 익숙한 학부 조건부확률로 먼저 확인해 보자.

들어가는 말의 주사위를 다시 가져온다.


```math
\Omega=\{1,2,3,4,5,6\}, \qquad B=\{2,4,6\}, \qquad A=\{4,5,6\}.
```


`\(B\)`는 짝수가 나오는 사건이고, `\(A\)`는 `\(4\)` 이상이 나오는 사건이다.

학부 공식으로 계산하면


```math
P(A\mid B)=\frac{P(\{4,6\})}{P(B)}=\frac{2/6}{3/6}=\frac23, \qquad P(A\mid B^c)=\frac{P(\{5\})}{P(B^c)}=\frac{1/6}{3/6}=\frac13.
```


이제 질문을 조금 바꿔 보자.

주사위를 던지기 **전에**, 결과가 짝수인지 홀수인지만 알려 주기로 약속했다고 하자.

이때 우리가 갖게 될 정보는


```math
\sigma(B)=\{\varnothing,B,B^c,\Omega\}
```


이다.

짝수인지 홀수인지는 구별할 수 있지만, 그 안에서 어느 눈이 나왔는지는 구별할 수 없다.

그러면 “이 정보 아래에서 `\(A\)`의 조건부확률은 얼마인가?”라는 질문에는 숫자 하나로 답할 수 없다.

짝수가 나오면 `\(2/3\)`이고, 홀수가 나오면 `\(1/3\)`이기 때문이다.

그래서 답은 `\(\omega\)`에 따라 값이 달라지는 함수가 된다.


```math
\boxed{ P(A\mid\sigma(B))(\omega) = \frac23\,1_B(\omega)+\frac13\,1_{B^c}(\omega) = \begin{cases} 2/3 & (\omega\in B)\\ 1/3 & (\omega\in B^c) \end{cases} }
```


주사위가 아니어도 `\(0<P(B)<1\)`인 사건 `\(B\)`라면 똑같이


```math
P(A\mid\sigma(B)) = P(A\mid B)1_B + P(A\mid B^c)1_{B^c}
```


라고 쓸 수 있다.

여기서 중요한 점이 처음 보인다.


```math
\boxed{\text{정보에 대한 조건부확률은 숫자가 아니다.}}
```


`\(\omega\)`에 따라 값이 달라지는 **확률변수**다.

조각 하나(`\(B\)` 또는 `\(B^c\)`)를 고정하면 학부에서 배운 숫자 하나가 나오지만, 어느 조각에 있는지가 정보로만 주어진 상태에서는 확률변수가 된다.

## 정보를 줄이거나 늘려 보면

약속을 바꿔 보자. 알려 주는 정보의 양에 따라 답이 어떻게 달라질까?

**아무것도 알려 주지 않기로 했다면** 우리가 갖는 정보는 `\(\{\varnothing,\Omega\}\)`다. 2절에서 본 대로 이 정보로는 상수밖에 만들 수 없고, 답은 어떤 눈이 나오든 같은 숫자다. 학부 공식으로도 `\(P(A\mid\Omega)=P(A)=1/2\)`이다.

**짝수인지 홀수인지만 알려 주기로 했다면** 방금 본 대로 `\(B\)`에서 `\(2/3\)`, `\(B^c\)`에서 `\(1/3\)`이다.

**나온 눈을 그대로 알려 주기로 했다면** 우리가 갖는 정보는 `\(\Omega\)`의 모든 부분집합, 곧 `\(\mathcal F=2^\Omega\)` 전체다. 이제 `\(A\)`가 일어났는지를 확실히 안다. 학부 공식으로 계산해도 `\(P(A\mid\{\omega\})=P(A\cap\{\omega\})/P(\{\omega\})\)`는 `\(\omega\in A\)`이면 `\(1\)`, 아니면 `\(0\)`이다. 즉 답은 `\(1_A\)` 자체다.

`\(\omega\)`마다 값을 적어 보면 다음과 같다.

| 알려 주는 정보 | `\(1\)` | `\(2\)` | `\(3\)` | `\(4\)` | `\(5\)` | `\(6\)` |
| --- | --- | --- | --- | --- | --- | --- |
| 없음: `\(\{\varnothing,\Omega\}\)` | `\(1/2\)` | `\(1/2\)` | `\(1/2\)` | `\(1/2\)` | `\(1/2\)` | `\(1/2\)` |
| 짝·홀: `\(\sigma(B)\)` | `\(1/3\)` | `\(2/3\)` | `\(1/3\)` | `\(2/3\)` | `\(1/3\)` | `\(2/3\)` |
| 나온 눈 전체: `\(2^\Omega\)` | `\(0\)` | `\(0\)` | `\(0\)` | `\(1\)` | `\(1\)` | `\(1\)` |

정보가 늘어날수록 답은 `\(\omega\)`에 따라 더 잘게 달라진다.


```math
\boxed{ P(A) \quad\longrightarrow\quad P(A\mid\sigma(B)) \quad\longrightarrow\quad 1_A }
```


아무것도 모르면 전체 평균인 숫자 하나로 답해야 하고, 모든 것을 알면 답이 `\(1_A\)` 자신이 된다. 그 사이의 정보에서는 정보가 구별하는 조각마다 따로 평균을 낸다.

학부에서 배운 숫자 `\(P(A)\)`도 아무 정보가 없을 때의 조건부확률, 곧 상수 확률변수로 볼 수 있는 셈이다.

## 이 확률변수가 가진 두 성질

`\(Z=P(A\mid\sigma(B))\)`라고 쓰자.

첫째, `\(Z\)`는 `\(B\)` 위에서 상수이고 `\(B^c\)` 위에서도 상수다.

짝수인지 홀수인지만 보고 값을 정했을 뿐, 어느 눈이 나왔는지는 사용하지 않았다.

둘째, `\(B\)` 위에서 적분하면


```math
\int_B Z\,dP = P(A\mid B)P(B) = P(A\cap B).
```


학부에서 배운 곱셈법칙이다.

`\(B^c\)` 위에서도 마찬가지로


```math
\int_{B^c} Z\,dP = P(A\mid B^c)P(B^c) = P(A\cap B^c)
```


이고, `\(\varnothing\)` 위에서는 양변이 모두 `\(0\)`이다.

`\(\Omega\)` 위에서 적분하면


```math
\int_\Omega Z\,dP = P(A\mid B)P(B)+P(A\mid B^c)P(B^c) = P(A).
```


주사위에서는 `\(\frac23\cdot\frac12+\frac13\cdot\frac12=\frac12=P(A)\)`다.

전확률의 법칙(law of total probability)이다.

`\(P(A\cap C)=\int_C 1_A\,dP\)`이므로 세 식을 한 줄로 모으면


```math
\boxed{ \int_C Z\,dP = \int_C 1_A\,dP \qquad \forall C\in\sigma(B). }
```


정리하면 학부 조건부확률로 만든 `\(Z\)`는

1. 주어진 정보 `\(\sigma(B)\)`만으로 값이 정해지고,
2. 그 정보가 구별할 수 있는 모든 사건에서 `\(1_A\)`와 적분이 같다.

이 두 성질이 다음 절에서 조건부 기댓값의 정의가 된다.

## 사건에서 확률변수로, 두 조각에서 `\(k\)`개 조각으로

`\(P(A)=E[1_A]\)`이므로 지금까지의 이야기는 확률변수 `\(1_A\)`의 조건부 평균에 대한 이야기이기도 하다.

`\(1_A\)` 대신 일반적인 확률변수 `\(Y\)`를 넣으면, 각 조각 안에서의 평균은


```math
E[Y\mid B] = \frac{E[Y1_B]}{P(B)}
```


이다.

`\(Y=1_A\)`이면 `\(E[1_A1_B]=P(A\cap B)\)`이므로 `\(E[Y\mid B]\)`가 정확히 `\(P(A\mid B)\)`다.

조각이 두 개일 필요도 없다.

`\(\Omega\)`가 서로 겹치지 않는 사건 `\(G_1,\dots,G_k\)`(각 `\(P(G_i)>0\)`)로 나뉘어 있고


```math
\mathcal G=\sigma(G_1,\dots,G_k)
```


라면, 같은 논리로


```math
\boxed{ E[Y\mid\mathcal G] = \sum_{i=1}^k E[Y\mid G_i]1_{G_i}, \qquad E[Y\mid G_i] = \frac{E[Y1_{G_i}]}{P(G_i)} }
```


라고 추측할 수 있다.

주사위 예는 `\(k=2\)`, `\(G_1=B\)`, `\(G_2=B^c\)`, `\(Y=1_A\)`인 경우다. 정보가 없을 때는 `\(k=1\)`(`\(G_1=\Omega\)`), 나온 눈을 모두 알려 줄 때는 `\(k=6\)`(눈 하나하나가 조각)인 경우다.

이 식이 추측이 아니라 정의가 강제하는 유일한 답이라는 것은 9절에서 보인다.

# 4. 조건부 기댓값의 정의

이제 일반적인 정의로 간다.

`\(Y\in L^1\)`, 즉


```math
E[|Y|]<\infty
```


라고 하자.

부분 `\(\sigma\)`-대수


```math
\mathcal G\subseteq\mathcal F
```


에 대해 확률변수 `\(Z\)`가 다음 두 조건을 만족하면


```math
Z=E[Y\mid\mathcal G]
```


라고 한다.

첫째,


```math
\boxed{ Z\text{는 }\mathcal G\text{-가측이고 적분가능하다.} }
```


둘째, 모든 `\(A\in\mathcal G\)`에 대해


```math
\boxed{ \int_A Z\,dP = \int_A Y\,dP. }
```


적분가능성은 두 번째 조건의 좌변이 의미를 갖기 위한 전제일 뿐이다.

이 두 조건이 전부다.

3절의 주사위에서 관찰한 두 성질을 그대로 요구 조건으로 삼은 것이다.

`\(\mathcal G=\sigma(B)\)`, `\(Y=1_A\)`로 두면 첫 번째 조건은 `\(Z\)`가 `\(B\)`와 `\(B^c\)` 위에서 각각 상수라는 것이고, 두 번째 조건은 전확률의 법칙이다.

달라진 점은 분자를 조각의 확률로 나누는 과정이 정의에서 사라졌다는 것이다.

그래서 확률이 `\(0\)`인 조각이 있어도, 조각이 셀 수 없이 많고 그 모두의 확률이 `\(0\)`이어도 이 정의는 그대로 쓸 수 있다.

## 두 극단에서 정의를 써 보기

정의를 가장 간단한 두 경우에 적용해 보자.

### 아무 정보도 없을 때: `\(\mathcal G=\{\varnothing,\Omega\}\)`

첫 번째 조건에 의해 `\(Z\)`는 `\(\{\varnothing,\Omega\}\)`-가측이어야 하고, 2절에서 본 대로 그런 확률변수는 상수 `\(c\)`뿐이다.

두 번째 조건에 `\(A=\Omega\)`를 넣으면


```math
c = \int_\Omega c\,dP = \int_\Omega Y\,dP = E[Y].
```


`\(A=\varnothing\)`에서는 양변이 모두 `\(0\)`이므로 더 확인할 것이 없다. 따라서


```math
\boxed{ E[Y\mid\{\varnothing,\Omega\}] = E[Y]. }
```


정확히는 오른쪽의 숫자를 상수 확률변수로 본 것이다.

### 모든 정보를 알 때: `\(\mathcal G=\mathcal F\)`

`\(Z=Y\)`로 두어 보자. `\(Y\)`는 `\(\mathcal F\)`-가측이고 적분가능하므로 첫 번째 조건을 만족한다. 두 번째 조건은 양변이 같은 식이 되어 저절로 성립한다.

따라서


```math
\boxed{ E[Y\mid\mathcal F]=Y \qquad\text{a.s.} }
```


a.s.가 붙는 것은 조건부 기댓값이 거의 확실하게만 하나로 정해지기 때문이다(8절).

### 그 사이

2절의 정보의 순서


```math
\{\varnothing,\Omega\} \subseteq \mathcal G \subseteq \mathcal F
```


에 대응해서


```math
\boxed{ E[Y] \quad\longrightarrow\quad E[Y\mid\mathcal G] \quad\longrightarrow\quad Y }
```


라고 생각할 수 있다.

정보가 적으면 평균내야 하고, 정보가 많아질수록 원래 `\(Y\)`에 가까워진다. 3절 주사위의 `\(P(A)\to P(A\mid\sigma(B))\to 1_A\)`가 바로 `\(Y=1_A\)`인 경우다.

이제 두 조건을 하나씩 일반적인 경우에서 읽어 보자.

# 5. 첫 번째 조건 — 알고 있는 정보만 사용해야 한다

첫 번째 조건


```math
Z\text{가 }\mathcal G\text{-가측}
```


이라는 것은


```math
\boxed{ Z\text{가 }\mathcal G\text{가 제공하는 정보만으로 결정되어야 한다} }
```


는 뜻이다.

예를 들어


```math
\mathcal G=\sigma(X)
```


라면 `\(\mathcal G\)`-가측인 실수값 확률변수는 언제나 어떤 Borel 가측함수 `\(g\)`에 대해


```math
Z=g(X)
```


형태로 쓸 수 있다.

이를 Doob–Dynkin lemma라고 한다.

여기서 `\(g(X)\)`는 두 가측함수 `\(X\)`와 `\(g\)`의 합성이다.


```math
(\Omega,\ \sigma(X)) \xrightarrow{\ X\ } (\mathbb R,\ \mathcal B(\mathbb R)) \xrightarrow{\ g\ } (\mathbb R,\ \mathcal B(\mathbb R))
```


반대로 이런 합성은 언제나 `\(\sigma(X)\)`-가측이므로, `\(\sigma(X)\)`-가측인 확률변수는 정확히 `\(g(X)\)` 꼴의 확률변수다.

따라서


```math
E[Y\mid X]
```


라는 것은 결국 어떤 함수 `\(g\)`가 있어서


```math
\boxed{ E[Y\mid X]=g(X) }
```


라고 쓸 수 있는 확률변수다.

즉 `\(Y\)`를 예측하면서 `\(X\)` 외의 숨겨진 정보를 몰래 사용해서는 안 된다.

머신러닝 언어로 번역하면


```math
\boxed{\text{prediction은 input }X\text{만 보고 만들어야 한다.}}
```


는 제약이다.

---

# 6. 두 번째 조건 — 알고 있는 모든 사건에서 평균을 맞춰야 한다

두 번째 조건은


```math
\int_A E[Y\mid\mathcal G]\,dP = \int_A Y\,dP \qquad \forall A\in\mathcal G
```


이다.

기댓값 표기로 쓰면


```math
\boxed{ E[1_AE[Y\mid\mathcal G]] = E[1_AY] \qquad \forall A\in\mathcal G. }
```


즉 현재 정보 `\(\mathcal G\)`로 구별할 수 있는 어떤 집단 `\(A\)`를 골라도, `\(Y\)`의 총합과 조건부 기댓값의 총합이 일치해야 한다.

따라서


```math
E[Y\mid\mathcal G]
```


는 세부적인 정보는 버리지만, `\(\mathcal G\)`가 볼 수 있는 수준에서는 `\(Y\)`의 평균을 정확히 보존한다.

직관적으로


```math
\boxed{ \text{보이지 않는 세부 정보는 평균내 버리되, 보이는 수준의 평균은 바꾸지 않는다.} }
```


라고 생각하면 된다.

특히 `\(A=\Omega\)`를 넣으면


```math
E[E[Y\mid\mathcal G]] = E[Y].
```


즉 조건부 평균을 다시 전체 평균내면 원래 평균으로 돌아온다.

law of total expectation의 가장 기본적인 형태다.

## `\(Y=1_A\)`이면 — 조건부확률

3절의 이야기를 일반적인 `\(\mathcal G\)`로 옮겨 보자.

사건 `\(A\in\mathcal F\)`에 대해 `\(E[1_A]=P(A)\)`이므로 자연스럽게


```math
\boxed{ P(A\mid\mathcal G) := E[1_A\mid\mathcal G] }
```


라고 정의한다.

3절에서 본 것처럼 이것도 숫자가 아니라 `\(\mathcal G\)`-가측 확률변수다.

두 번째 조건은 모든 `\(B\in\mathcal G\)`에 대해


```math
\boxed{ \int_B P(A\mid\mathcal G)\,dP = P(A\cap B) }
```


가 된다.

이것은 학부의 곱셈법칙


```math
P(A\mid B)P(B)=P(A\cap B)
```


를 일반적인 정보 `\(\mathcal G\)`로 확장한 것이다.

`\(B=\Omega\)`를 넣으면 전확률의 법칙 `\(E[P(A\mid\mathcal G)]=P(A)\)`가 된다.

# 7. 존재성 — 8강의 Radon–Nikodym 정리

정의를 만들었다고 해서 그런 `\(Z\)`가 실제로 존재한다는 보장은 없다.

여기서 8강의 Radon–Nikodym 정리가 사용된다. 8강 21절에서 미리 본 논증을 다시 정리해 보자.

우선 `\(Y\ge0\)`이라고 하자.

`\(\mathcal G\)` 위에서


```math
\nu(A) = \int_A Y\,dP, \qquad A\in\mathcal G
```


라고 정의한다.

그러면 `\(\nu\)`는 `\(\mathcal G\)` 위의 측도다.

그리고


```math
P(A)=0
```


이면


```math
\nu(A) = \int_A Y\,dP = 0.
```


따라서


```math
\boxed{ \nu\ll P|_{\mathcal G}. }
```


Radon–Nikodym 정리에 의해 어떤 `\(\mathcal G\)`-가측함수 `\(Z\)`가 존재하여


```math
\nu(A) = \int_A Z\,dP \qquad \forall A\in\mathcal G
```


가 된다.

그런데 `\(\nu\)`의 정의가


```math
\nu(A) = \int_A Y\,dP
```


였으므로


```math
\boxed{ \int_A Z\,dP = \int_A Y\,dP \qquad \forall A\in\mathcal G. }
```


언뜻 보면 `\(Z=Y\)`로 잡으면 끝나는 것 같다.

하지만 `\(Y\)`는 `\(\mathcal F\)`-가측일 뿐 일반적으로 `\(\mathcal G\)`-가측이 아니다.

`\(\nu\)`와 `\(P|_{\mathcal G}\)`는 `\(\mathcal G\)` 위의 측도이므로 그 RN derivative도 `\(\mathcal G\)`-가측이어야 하고, `\(Y\)`에게는 그 자격이 없다.

같은 식 `\(A\mapsto\int_A Y\,dP\)`를 `\(\mathcal F\)` 전체에서 `\(P\)`와 비교했다면 RN derivative는 `\(Y\)` 자신이었을 것이다. 4절에서 본 `\(E[Y\mid\mathcal F]=Y\)`가 바로 이 경우다. `\(\mathcal G\)`로 **제한했기 때문에** 다른 답이 나온다.

`\(\mathcal G\)`가 주는 정보만으로 만든 함수 중에 이 등식을 만족하는 것이 **존재한다**는 보장, 그것이 RN 정리가 해 주는 일이다.

따라서 바로


```math
\boxed{ Z=E[Y\mid\mathcal G]. }
```


이다.

즉


```math
\boxed{ E[Y\mid\mathcal G] = \frac{d\nu}{d(P|_{\mathcal G})}, \qquad \nu(A)=\int_A Y\,dP. }
```


8강에서 배운


```math
\text{측도} \longrightarrow \text{RN derivative}
```


라는 구조가 그대로 돌아왔다.

일반적인 `\(Y\in L^1\)`에서는


```math
Y=Y^+-Y^-
```


로 나누어 같은 논리를 적용하면 된다.

# 8. 조건부 기댓값은 거의 확실하게만 유일하다

두 확률변수 `\(Z_1,Z_2\)`가 모두 조건부 기댓값의 정의를 만족하면


```math
\boxed{ Z_1=Z_2 \qquad P\text{-a.s.} }
```


이다. a.s.는 측도가 0인 집합에서만 다르다는 뜻이다. 증명은 아래 곁가지로 미룬다.

`\(Z\)`가 정의를 만족하고 `\(N\in\mathcal G\)`가 `\(P(N)=0\)`인 집합이면, `\(N\)` 위의 값만 아무 상수 `\(c\)`로 바꾼


```math
Z' = Z1_{N^c} + c\,1_N
```


도 여전히 정의를 만족한다.

`\(Z'\)`도 `\(\mathcal G\)`-가측이고, 두 번째 조건은 적분값이 같기만을 요구하는데 확률 `\(0\)`인 집합 위의 값은 적분에 영향을 주지 않기 때문이다.

이렇게 a.s.로 같은 여러 확률변수를 각각 조건부 기댓값의 한 **version**이라고 부른다.

주의할 점은 `\(N\)`이 `\(\mathcal G\)`에 속해야 한다는 것이다.

`\(\mathcal G\)`에 속하지 않는 집합 위에서 값을 바꾸면 첫 번째 조건, 곧 `\(\mathcal G\)`-가측성이 깨질 수 있다.

예를 들어 `\(\mathcal G=\{\varnothing,\Omega\}\)`라면 `\(\mathcal G\)` 안에서 확률이 `\(0\)`인 집합은 `\(\varnothing\)`뿐이므로 값을 바꿔 볼 곳이 없다. 4절에서 본 대로 `\(E[Y\mid\mathcal G]\)`는 모든 점에서 상수 `\(E[Y]\)` 하나로 정해진다.

이 점은 잠시 뒤


```math
E[Y\mid X=x]
```


를 이해할 때 매우 중요해진다.

---

## 곁가지: 왜 a.s.로 유일한가

> 증명이 궁금하지 않다면 건너뛰어도 좋다. 다음 절로 넘어가는 데 지장은 없다.

위의 유일성은 두 조건을 한 번씩 쓰면 나온다.


```math
A=\{Z_1>Z_2\}
```


라 하자.

`\(Z_1,Z_2\)`가 모두 `\(\mathcal G\)`-가측이므로 `\(A\in\mathcal G\)`다. 첫 번째 조건은 여기서 쓰인다.

`\(A\in\mathcal G\)`이므로 두 번째 조건을 `\(Z_1\)`과 `\(Z_2\)`에 각각 적용할 수 있고


```math
\int_A Z_1\,dP = \int_A Y\,dP = \int_A Z_2\,dP, \qquad\text{즉}\qquad \int_A (Z_1-Z_2)\,dP = 0.
```


그런데 `\(A\)` 위에서는 `\(Z_1-Z_2>0\)`이다.

`\(A_n=\{Z_1-Z_2>1/n\}\)`이라 하면 `\(A_n\subseteq A\)`이고 `\(A\)` 위에서 적분하는 함수가 양수이므로


```math
0 = \int_A (Z_1-Z_2)\,dP \ge \int_{A_n} (Z_1-Z_2)\,dP \ge \frac1n P(A_n).
```


따라서 모든 `\(n\)`에 대해 `\(P(A_n)=0\)`이고, `\(A=\bigcup_n A_n\)`이므로 `\(P(A)=0\)`이다.

`\(Z_1,Z_2\)`의 역할을 바꾸면 `\(P(Z_2>Z_1)=0\)`도 같은 방법으로 나오므로 `\(Z_1=Z_2\)` a.s.다.

# 9. 유한한 정보의 경우로 돌아가기

이 절에서는 3절에서 추측으로 적어 둔 유한한 정보에서의 식을 정의로부터 유도한다. 3절의 식을 그대로 받아들이고 넘어갈 독자는 이 절을 건너뛰어도 좋다. 다만 마지막 두 소절(Radon–Nikodym이 필요 없는 이유, a.s. 모호함이 없는 이유)은 11절에서 다시 쓰이므로 그 부분만큼은 읽기를 권한다.

3절에서 정보가 유한 개의 조각으로 주어질 때


```math
E[Y\mid\mathcal G] = \sum_{i=1}^k E[Y\mid G_i]1_{G_i}
```


라고 썼다.

그때는 정의가 없었으므로 학부 조건부확률에서 출발한 추측으로 받아들였다.

이제 정의가 있으니 이 식이 맞는지 확인할 수 있다.

그런데 확인하는 것보다 더 좋은 것이 있다.


```math
\boxed{ \text{이 식은 추측이 아니라 두 조건이 강제하는 유일한 답이다.} }
```


라는 것을 보이는 것이다.

## `\(\mathcal G\)`가 어떻게 생겼는지 먼저 본다

3절과 같은 상황이다.

`\(G_1,\dots,G_k\)`는 서로 겹치지 않으면서 `\(\Omega\)`를 덮는다.


```math
G_i\cap G_j=\varnothing\ (i\ne j), \qquad \bigcup_{i=1}^kG_i=\Omega
```


그리고 각 `\(P(G_i)>0\)`이라고 하자.

겹치지 않는다는 조건이 핵심이다.

이때


```math
\mathcal G=\sigma(G_1,\dots,G_k) = \Big\{\textstyle\bigcup_{i\in I}G_i \;:\; I\subseteq\{1,\dots,k\}\Big\}
```


가 성립한다.

오른쪽 집합족이 `\(\sigma\)`-대수라는 것은 분할이기 때문에 바로 보인다.


```math
\Big(\bigcup_{i\in I}G_i\Big)^{c} = \bigcup_{i\notin I}G_i, \qquad \Big(\bigcup_{i\in I}G_i\Big)\cap\Big(\bigcup_{j\in J}G_j\Big) = \bigcup_{i\in I\cap J}G_i.
```


즉 여집합은 첨자의 여집합이 되고 교집합은 첨자의 교집합이 되어, 이 족을 벗어나지 않는다.

그리고 `\(G_1,\dots,G_k\)`를 모두 담는 가장 작은 `\(\sigma\)`-대수이므로 `\(\sigma(G_1,\dots,G_k)\)`와 같다.

그래서 `\(\mathcal G\)`는 원소가 `\(2^k\)`개인 유한 `\(\sigma\)`-대수이고, `\(G_i\)`들은 더 이상 쪼갤 수 없는 최소 단위다.

이것을 원자(atom)라고 부른다.

## 첫 번째 조건이 형태를 결정한다

`\(Z\)`가 `\(\mathcal G\)`-가측이라는 것은


```math
\boxed{ Z\text{가 각 원자 }G_i\text{ 위에서 상수다} }
```


와 같은 말이다.

한쪽은 분명하다.

`\(Z\)`가 각 `\(G_i\)` 위에서 상수라면, 임의의 Borel 집합 `\(D\)`에 대해 역상


```math
\{Z\in D\}=Z^{-1}(D)=\{\omega\in\Omega: Z(\omega)\in D\}
```


은 값이 `\(D\)` 안에 들어가는 원자들을 모은 것, 즉 `\(G_i\)`들의 합집합이다.

따라서 `\(\mathcal G\)`에 속하고, `\(Z\)`는 `\(\mathcal G\)`-가측이다.

반대쪽을 보자.

어떤 원자 `\(G_i\)` 안에 두 점 `\(\omega,\omega'\)`가 있어서


```math
Z(\omega)=a\ne b=Z(\omega')
```


라고 하자.

`\(D=\{a\}\)`로 두면 `\(D\)`는 Borel 집합이고, `\(Z\)`가 `\(\mathcal G\)`-가측이라는 가정에서


```math
Z^{-1}(D)\in\mathcal G
```


이다.

이 역상은 `\(\omega\)`는 품고 `\(\omega'\)`는 품지 않는다.

따라서


```math
\varnothing \;\ne\; Z^{-1}(D)\cap G_i \;\subsetneq\; G_i
```


이다. 원자 `\(G_i\)`가 진짜로 두 조각으로 잘린 것이다.

그런데 `\(\mathcal G\)`의 원소는 앞에서 본 대로 `\(\bigcup_{j\in I}G_j\)` 꼴이므로, 원자와의 교집합은


```math
\Big(\bigcup_{j\in I}G_j\Big)\cap G_i =
\begin{cases}
G_i & (i\in I) \\
\varnothing & (i\notin I)
\end{cases}
```


둘 중 하나뿐이다.

따라서 모순이다.

그러므로 후보는


```math
Z=\sum_{i=1}^k c_i1_{G_i}
```


꼴뿐이다.


```math
\boxed{ \text{첫 번째 조건은 무한히 많던 후보를 미지수 }k\text{개로 줄였다.} }
```


## 두 번째 조건이 값을 결정한다

이제 두 번째 조건에 `\(A=G_j\)`를 넣는다. `\(G_j\in\mathcal G\)`이므로 넣어도 된다.

좌변은


```math
\int_{G_j}Z\,dP = \sum_{i=1}^k c_iP(G_i\cap G_j) = c_jP(G_j)
```


이다. 분할이므로 `\(i\ne j\)`인 항은 모두 사라진다.

우변은


```math
\int_{G_j}Y\,dP = E[Y1_{G_j}]
```


이다.

`\(P(G_j)>0\)`이므로 나눌 수 있고


```math
\boxed{ c_j = \frac{E[Y1_{G_j}]}{P(G_j)} = E[Y\mid G_j]. }
```


선택의 여지가 없다.


```math
\boxed{ \text{두 번째 조건은 남은 자유도 }k\text{개를 정확히 다 소진했다.} }
```


## 거꾸로도 성립한다

지금까지 보인 것은 “정의를 만족하는 `\(Z\)`가 있다면 반드시 이 꼴이어야 한다”이다.

이제 이 `\(Z\)`가 실제로 정의를 만족하는지 보자.

`\(\mathcal G\)`-가측성은 구성상 분명하고, 유한개의 지시함수의 일차결합이므로 적분가능하다.

일반적인


```math
A=\bigcup_{i\in I}G_i\in\mathcal G
```


에 대해서는


```math
\int_AZ\,dP = \sum_{i\in I}c_iP(G_i) = \sum_{i\in I}E[Y1_{G_i}] = E[Y1_A] = \int_AY\,dP
```


이다.

즉 원자 위에서만 맞추면 나머지는 가법성으로 따라온다.

이렇게 해서 3절의 식이 증명되었다.

## 주사위로 돌아가기 — 학부 공식은 정의에서 나온다

3절의 주사위 예는 `\(k=2\)`, `\(G_1=B\)`, `\(G_2=B^c\)`, `\(Y=1_A\)`인 경우다.

방금 두 조건만으로 구한 계수


```math
c_j = \frac{E[Y1_{G_j}]}{P(G_j)}
```


에 이것을 넣으면, `\(1_A1_B=1_{A\cap B}\)`이므로


```math
P(A\mid\sigma(B)) = E[1_A\mid\sigma(B)] = \frac{P(A\cap B)}{P(B)}1_B + \frac{P(A\cap B^c)}{P(B^c)}1_{B^c}.
```


이 계산에서 학부 조건부확률의 정의는 한 번도 쓰지 않았다.

사용한 것은 조건부 기댓값의 두 조건뿐이다.

그런데 `\(B\)` 위에서 나온 값


```math
\boxed{ P(A\mid\sigma(B))(\omega) = \frac{P(A\cap B)}{P(B)} \qquad (\omega\in B) }
```


는 학부에서 `\(P(A\mid B)\)`라고 정의했던 바로 그 값이다.

3절에서는 학부 공식에서 출발해 두 성질을 관찰했고, 여기서는 반대로 두 성질에서 출발해 학부 공식에 도착했다.

즉 측도론적 조건부 기댓값은 학부 공식을 버리는 것이 아니다.


```math
\boxed{ \text{학부 조건부확률을 포함하면서 확률 }0\text{인 경우까지 갈 수 있도록 확장한 것이다.} }
```


## 유한한 경우에는 Radon–Nikodym이 필요 없다

7절에서는 존재성을 위해 RN 정리를 꺼냈다.

그런데 방금 우리는 RN 없이 `\(Z\)`를 직접 만들었다.

연립방정식을 손으로 풀었을 뿐이다.


```math
\boxed{ \text{확률이 양수인 원자 }k\text{개로 나뉘면 조건부 기댓값은 나눗셈 }k\text{번으로 끝난다.} }
```


그렇다면 `\(\mathcal G=\sigma(X)\)`이고 `\(X\)`가 연속형이면 무엇이 달라질까?

원자가 사라지는 것은 아니다.

3강에서 본 것처럼 `\(X\)`가 같은 값을 주는 결과들은 `\(X\)`만 보고 구별할 수 없으므로, `\(\sigma(X)\)`의 원자는 각 `\(x\)`에 대한


```math
\{X=x\}
```


다.

`\(\sigma(X)\)`의 원소 `\(\{X\in D\}\)`는 이 원자를 통째로 품거나 전혀 품지 않으므로, 앞에서 본 대로 `\(E[Y\mid X]\)`는 각 원자 위에서 상수다. `\(E[Y\mid X]=g(X)\)`라고 쓸 수 있는 이유를 원자의 말로 다시 본 것이다.

달라지는 것은 두 가지다.

1. 원자가 셀 수 없이 많다.
2. 모든 원자의 확률이 `\(0\)`이다.

그래서 나눌 `\(P(X=x)\)`가 모두 `\(0\)`이고, 원자 하나하나를 따로 보아서는 값을 정할 수 없다. 원자 하나에 대한 두 번째 조건은 `\(0=0\)`이 되어 아무것도 알려 주지 않기 때문이다(바로 아래에서 다시 본다).

원자들을 셀 수 없이 많이 모은 집합 `\(\{X\in D\}\)`들 위에서 적분이 맞도록 값을 한꺼번에 정해야 한다.

나눗셈 대신 적분이 맞는 밀도를 찾아 주는 것, 그것이 RN derivative다.

## 유한한 경우에는 a.s.의 모호함도 없다

8절에서 조건부 기댓값은 거의 확실하게만 유일하다고 했다.

유한한 경우에는 그 모호함이 사라진다.

`\(\mathcal G\)`-가측인 두 version `\(Z_1,Z_2\)`는 각각 원자 위에서 상수인데, 어떤 원자에서 두 상수가 다르면 `\(\{Z_1\ne Z_2\}\)`가 그 원자 전체를 품는다.

`\(P(G_i)>0\)`이므로 이것은 a.s. 일치와 어긋난다.

따라서


```math
\boxed{ P(G_i)>0\text{인 원자 위에서는 값이 모든 점에서 결정된다.} }
```


8절의 말로 하면, `\(\mathcal G\)` 안에서 확률이 `\(0\)`인 집합이 `\(\varnothing\)`뿐이므로 값을 바꿔 볼 곳이 없는 것이다.

반대로 만약 `\(P(G_i)=0\)`인 원자가 하나 있었다면 `\(A=G_i\)`에 대한 두 번째 조건은


```math
c_i\cdot P(G_i)=E[Y1_{G_i}] \quad\Longrightarrow\quad c_i\cdot0=0
```


이 되어 `\(c_i\)`에 대해 아무것도 말해 주지 않는다. `\(c_i\)`는 아무 값이어도 된다.

모호함은 확률이 `\(0\)`인 조각에서만 생긴다.

그리고 `\(P(X=x)=0\)`이라는 것은 정확히 조각 `\(\{X=x\}\)`의 확률이 `\(0\)`이라는 뜻이다.

# 10. `\(E[Y\mid X]\)`는 무엇인가

확률변수 `\(X\)`가 주어졌을 때


```math
\boxed{ E[Y\mid X] := E[Y\mid\sigma(X)] }
```


라고 정의한다.

즉 `\(X\)`에 조건화한다는 것은 사건 `\(\{X=x\}\)` 하나에 조건화한다는 뜻이 아니다.


```math
\boxed{ X\text{를 관측함으로써 알 수 있는 모든 정보에 조건화한다} }
```


는 뜻이다.

그리고 `\(E[Y\mid X]\)`는 `\(\sigma(X)\)`-가측이므로


```math
E[Y\mid X]=g(X)
```


인 어떤 가측함수 `\(g\)`가 존재한다.

이 `\(g\)`를 이용해 흔히


```math
\boxed{ g(x)=E[Y\mid X=x] }
```


라고 쓴다.

하지만 여기에는 중요한 미묘함이 있다.

---

# 11. `\(E[Y\mid X]\)`와 `\(E[Y\mid X=x]\)`는 같은 표기가 아니다


```math
E[Y\mid X]
```


는 명확하다.

이것은 `\(\Omega\)` 위에 정의된 하나의 확률변수다.

반면


```math
E[Y\mid X=x]
```


는 특정 `\(x\)`에서의 숫자처럼 보인다.

`\(E[Y\mid X]=g(X)\)`라 할 때 `\(g\)`는 `\(P_X\)`-a.e.에서만 유일하다.

즉


```math
P_X(N)=0
```


인 집합 `\(N\)` 위에서 `\(g\)`의 값을 마음대로 바꾸더라도


```math
g(X)
```


는 a.s.로 같은 확률변수로 남는다.

따라서 어떤 특정한 `\(x\)`가


```math
P_X(\{x\})=0
```


인 점이라면, 조건부 기댓값의 정의만으로


```math
g(x)
```


의 값이 반드시 하나로 정해지는 것은 아니다.

그래서 엄밀하게는


```math
\boxed{ E[Y\mid X]\text{는 a.s.로 잘 정의되지만, }E[Y\mid X=x]\text{의 점별 값은 version 선택이 필요하다.} }
```


충분히 좋은 공간에서는 다음 강에서 배울 regular conditional distribution을 이용해


```math
x\mapsto P(Y\in A\mid X=x)
```


를 가측하게 선택할 수 있다.

하지만 그 역시 `\(P_X\)`-null set 위에서는 일반적으로 유일하지 않다.

## 우리가 쓰던 공식은 그 version 중 하나다

그렇다면 들어가는 말의 질문으로 돌아가 보자.

`\(P(X=x)=0\)`인데도 매일 쓰던


```math
E[Y\mid X=x] = \frac{\int y\,p(x,y)\,dy}{p_X(x)} = \int y\,p(y\mid x)\,dy
```


는 무엇이었을까?

`\((X,Y)\)`가 Lebesgue 측도에 대한 공동밀도 `\(p(x,y)\)`를 갖고 `\(Y\in L^1\)`이라고 하자.

`\(X\)`의 주변밀도는 `\(p_X(x)=\int p(x,y)\,dy\)`다.


```math
g(x) = \begin{cases} \dfrac{\int y\,p(x,y)\,dy}{p_X(x)} & (p_X(x)>0)\\[6pt] 0 & (p_X(x)=0) \end{cases}
```


로 두자.

`\(p_X(x)=0\)`인 곳의 값은 아무렇게나 정해도 된다. `\(X\)`가 그런 곳에 떨어질 확률은 `\(\int_{\{p_X=0\}}p_X(x)\,dx=0\)`이기 때문이다.

`\(g(X)\)`가 두 조건을 만족하는지 확인하자.

첫 번째 조건부터 보자. `\(g(X)\)`는 `\(X\)`의 함수이므로 `\(\sigma(X)\)`-가측이다. 또 `\(|g(x)|\,p_X(x)\le\int|y|\,p(x,y)\,dy\)`이므로 `\(E[|g(X)|]\le E[|Y|]<\infty\)`, 즉 적분가능하다.

두 번째 조건을 보자. `\(\sigma(X)\)`의 원소는 Borel 집합 `\(D\)`에 대해 `\(\{X\in D\}\)` 꼴이므로 이런 집합 위에서만 확인하면 된다.

좌변은 `\(X\)`의 분포만으로 계산할 수 있으므로


```math
\int_{\{X\in D\}} g(X)\,dP = \int_D g(x)\,p_X(x)\,dx = \int_D\int y\,p(x,y)\,dy\,dx.
```


마지막 등호에서 `\(p_X(x)\)`가 약분되었다. 나눗셈이 적분 안에서 곱셈과 상쇄된 것이다. (`\(p_X(x)=0\)`인 `\(x\)`에서는 `\(p(x,\cdot)=0\)` a.e.이므로 양쪽이 모두 `\(0\)`이다.)

우변은 공동밀도로 계산하면


```math
\int_{\{X\in D\}} Y\,dP = E[1_D(X)\,Y] = \int_{\mathbb R^2} 1_D(x)\,y\,p(x,y)\,d(x,y) = \int_D\int y\,p(x,y)\,dy\,dx.
```


두 번째 등호는 3강의 push-forward다. 공동밀도가 있으므로 평면 위의 적분, 곧 2차원 Lebesgue 측도에 대한 적분으로 쓸 수 있다.

마지막 등호에서 평면 위의 적분을 `\(y\)` 먼저, 그다음 `\(x\)` 순서의 반복적분으로 바꾼 것이 7강의 Fubini다.

양변이 같으므로


```math
\boxed{ E[Y\mid X] = g(X), \qquad g(x) = \frac{\int y\,p(x,y)\,dy}{p_X(x)}. }
```


학부에서 배운 조건부밀도 공식은 조건부 기댓값의 한 version이었던 것이다.

이것이 연속확률변수에서


```math
P(X=x)=0
```


인데도 `\(p(y\mid x)\)`를 사용할 수 있는 정확한 배경이다.

`\(\{X=x\}\)`라는 사건 하나에 조건화한 것이 아니라, `\(\sigma(X)\)` 전체에 조건화해서 얻은 함수 `\(g\)`를 점 `\(x\)`에서 읽은 것이다.

다만 이것도 여러 version 중 하나라는 사실은 변하지 않는다.

`\(X\)`가 연속분포면 한 점 `\(\{x_0\}\)`은 `\(P_X\)`-null set이다. 그래서 `\(g\)`의 값을 그 점에서만 바꾼


```math
\tilde g(x)=\begin{cases} g(x) & (x\ne x_0)\\ g(x_0)+7 & (x=x_0) \end{cases}
```


도 `\(\tilde g(X)=g(X)\)` a.s.이므로 8절에서 본 대로 여전히 정의를 만족한다. 정의는 `\(E[Y\mid X=x_0]\)`라는 **숫자 하나**를 지정해 주지 않는다.

모호함은 한 겹 더 있다. 공식에 들어가는 공동밀도 `\(p\)` 자체가 평면 위에서 a.e.로만 유일하다(8강 7절). 직선 `\(\{x=x_0\}\)`은 평면에서 넓이가 `\(0\)`이므로 그 위에서만 `\(p\)`를 바꿔도 `\(p\)`는 여전히 `\((X,Y)\)`의 공동밀도다. 그런데 분자 `\(\int y\,p(x_0,y)\,dy\)`와 분모 `\(p_X(x_0)\)`는 달라진다.

8강 12절에서 밀도는 Lebesgue-a.e.로만 유일하므로 한 점에서의 값은 연속인 version을 쓰기로 약속해야 정해진다고 했다. 같은 약속이 여기서도 적용된다.


```math
\boxed{ \text{두 연속함수가 a.e.로 같으면 모든 점에서 같다.} }
```


두 연속함수의 차 `\(h\)`가 `\(h(x_0)\ne0\)`이라면 연속성에 의해 `\(x_0\)` 주변의 열린 구간 전체에서 `\(h\ne0\)`이다. 비어 있지 않은 열린 구간은 Lebesgue 측도가 양수이므로 “영집합 위에서만 다르다”가 될 수 없다.

따라서 연속인 version은 있으면 하나뿐이고, 그것을 쓰기로 하면 점별 값이 고정된다. 다만 `\(g\)`의 기준측도는 Lebesgue가 아니라 `\(P_X\)`이므로 정확히는 `\(P_X\)`의 support 위에서 하나로 정해진다. 우리가 `\(g(x)\)`를 읽는 곳은 언제나 `\(p_X(x)>0\)`인 `\(x\)`이니 실질적인 제약은 아니다.

`\(p\)`가 연속이면 (적분과 극한을 바꿀 수 있는 정도의 조건에서) `\(p_X\)`도 연속이고, `\(p_X(x)>0\)`인 곳에서 `\(g\)`도 연속이다. 교과서 공식에 `\(x\)`를 대입해 답을 하나 읽을 때 우리는 무수히 많은 version 중 연속인 것을 이미 고르고 있다. 아무도 그렇게 말해 주지 않았을 뿐이다.

이 약속이 무엇까지 해 주는지도 분명히 해 두자. 고정된 `\(\sigma(X)\)` 안에서 한 점의 값을 고르는 문제를 없앨 뿐이다. `\(\sigma\)`-대수 자체가 달라져서 답이 달라지는 일은 그대로 남는다. 그것이 다음 소절의 내용이다.

## 곁가지의 역설을 다시 보면

1절의 곁가지에서는 정사각형 위의 균일분포 `\((X,Y)\)`를 대각선 `\(\{Y=X\}\)`에 조건화했다. 띠로 줄이면 `\(X\)`의 평균이 `\(1/2\)`, 쐐기로 줄이면 `\(2/3\)`이 나왔다.

이제 그 이유를 말할 수 있다.

띠 `\(\{|Y-X|<\varepsilon\}\)`는 차이 `\(\Delta=Y-X\)`를 관측해 그 값이 `\(0\)` 근처라는 것을 알게 된 상황이다.

쐐기 `\(\{|Y/X-1|<\varepsilon\}\)`는 비율 `\(R=Y/X\)`를 관측해 그 값이 `\(1\)` 근처라는 것을 알게 된 상황이다.

즉 두 방법은 서로 다른 정보에 조건화했다.


```math
E[X\mid \Delta]=E[X\mid\sigma(Y-X)], \qquad E[X\mid R]=E[X\mid\sigma(Y/X)].
```


대각선은 두 `\(\sigma\)`-대수 모두의 원자다.


```math
\{Y=X\}=\{\Delta=0\}\in\sigma(\Delta), \qquad \{Y=X\}=\{R=1\}\in\sigma(R).
```


하지만 확률이 `\(0\)`인 원자이므로, 9절에서 본 대로 각 조건부 기댓값의 정의는 그 위의 값을 정해 주지 않는다.

값을 정해 주는 것은 이웃한 원자들, 곧 `\(\{\Delta=\delta\}\)`들과 `\(\{R=r\}\)`들이다.

방금 공식에서 조건화하는 변수를 `\(\Delta\)` 또는 `\(R\)`로, 평균낼 변수를 `\(X\)`로 바꿔 계산해 보자.

`\((X,\Delta)\)`로 변수를 바꾸면 `\(Y=X+\Delta\)`라 `\(y\)`를 평행이동만 하는 셈이므로 Jacobian이 `\(1\)`이고, 공동밀도는 가능한 범위 위에서 `\(1\)`이다. `\(\delta=0\)`일 때 `\(x\)`의 범위는 `\([0,1]\)` 전체이므로


```math
E[X\mid \Delta=0]=\frac{\int_0^1 x\cdot1\,dx}{\int_0^1 1\,dx}=\frac12.
```


`\((X,R)\)`로 변수를 바꾸면 `\(Y=RX\)`이므로 `\(\partial y/\partial r=x\)`, 곧 Jacobian이 `\(x\)`다(3강 16절). 넓이 원소가 `\(dx\,dy=x\,dx\,dr\)`로 바뀌는 것이고, 공동밀도는 가능한 범위 `\(\{0\le r\le 1/x\}\)` 위에서 `\(x\)`다. `\(r=1\)`일 때는 `\(rx\le1\)`이 `\(x\le1\)`과 같아 잘리는 부분이 없으므로 `\(x\)`의 범위는 역시 `\([0,1]\)`이고


```math
E[X\mid R=1]=\frac{\int_0^1 x\cdot x\,dx}{\int_0^1 x\,dx}=\frac{1/3}{1/2}=\frac23.
```


곁가지의 두 극한이 그대로 나왔다.

두 Jacobian `\(1\)`과 `\(x\)`는 곁가지에서 띠의 두께가 어디서나 `\(2\varepsilon\)`, 쐐기의 두께가 `\(2\varepsilon x\)`였던 것과 같은 사실이다.

우연이 아니다. 띠 `\(S_\varepsilon=\{|\Delta|<\varepsilon\}\)`는 `\(\sigma(\Delta)\)`에 속하므로, 두 번째 조건에 의해 `\(E[X\mid S_\varepsilon]\)`은 `\(|\delta|<\varepsilon\)`인 `\(\delta\)`들에서의 `\(E[X\mid \Delta=\delta]\)`를 평균낸 값이다. 이 함수는 `\(\delta\)`에 대해 연속이므로 `\(\varepsilon\to0\)`이면 `\(E[X\mid \Delta=0]\)`으로 간다. 쐐기와 `\(R\)`도 마찬가지다.

두 답은 모두 옳다.

같은 집합 `\(\{Y=X\}\)` 위의 값이지만, 서로 다른 `\(\sigma\)`-대수에 대한 조건부 기댓값의 값이기 때문이다.


```math
\boxed{ \text{조건부 기댓값은 사건 하나가 아니라 그 사건을 원자로 품은 }\sigma\text{-대수 전체에 딸려 있다.} }
```


“대각선 위에서 `\(X\)`의 평균은?”이라는 질문은 **어떤 관측을 통해** 대각선 위에 있음을 알게 되었는지 정하기 전까지는 답이 없다. 1절에서 확률 `\(0\)`인 집합 `\(B\)` 자체만으로는 `\(P(A\mid B)\)`가 결정되지 않는다고 한 말의 뜻이 이것이다.

# 12. 그런데 아직 문제가 하나 남아 있다

11절에서는 `\(E[Y\mid X=x]\)`의 점별 값을 정하려면 version을 골라야 한다는 것을 보았다.

같은 문제가 조건부확률에서는 더 까다로운 형태로 나타난다.

6절처럼 고정된 사건 `\(A\)`에 대해


```math
P(A\mid\mathcal G) = E[1_A\mid\mathcal G]
```


를 정의하는 것은 문제가 없다.

하지만 우리가 실제로 원하는 것은 때때로 더 강하다.

각 `\(\omega\)`가 주어졌을 때


```math
A \longmapsto P(A\mid\mathcal G)(\omega)
```


가 **하나의 확률측도**가 되었으면 한다.

그래야


```math
P(Y\in dy\mid X=x)
```


같은 표현을 실제 분포로 다룰 수 있다.

여기서 미묘한 문제가 생긴다.

조건부 기댓값은 각 `\(A\)`에 대해 a.s.로만 유일하다.

즉 `\(A\)`마다 서로 다른 null set 위에서 값을 바꿀 수 있다.

사건을 가산 개만 생각한다면 그 null set들을 합쳐도 여전히 null set이므로 문제가 없다.

진짜 어려움은 모든 measurable `\(A\)`에 대해 version을 **동시에** 선택하여


```math
A\mapsto P(A\mid\mathcal G)(\omega)
```


가 거의 모든 `\(\omega\)`에서

1. `\(P(\Omega\mid\mathcal G)(\omega)=1\)`,
2. `\(P(\varnothing\mid\mathcal G)(\omega)=0\)`,
3. 서로소 `\(A_1,A_2,\dots\)`에 대해 `\(P\left(\bigcup_n A_n\mid\mathcal G\right)(\omega) = \sum_n P(A_n\mid\mathcal G)(\omega)\)`

를 모두 만족하도록 맞추는 것이다.

사건마다 따로 얻은 a.s. equivalence class가 자동으로 이러한 **점별 확률측도 하나**를 주는 것은 아니다.

그래서 다음 강에서는 새로운 객체를 도입한다.


```math
\boxed{ K(\omega,A). }
```


첫 번째 변수 `\(\omega\)`에 대해서는 가측함수이고,

두 번째 변수 `\(A\)`에 대해서는 확률측도인 객체다.

`\(\mathcal G=\sigma(X)\)`일 때는 `\(\omega\)` 대신 관측값 `\(x\)`를 첫 번째 변수로 삼아


```math
K(x,A)=P(Y\in A\mid X=x)
```


처럼 쓰는 경우가 많다. 24절과 다음 강에서 쓰는 `\(K(x,A)\)`가 이 형태다.

이것이


```math
\boxed{\text{probability kernel}}
```


이다.

# 13. `\(L^2\)`에서 조건부 기댓값은 직교사영이다

이제 6강의 `\(L^2\)` 기하가 돌아온다.

`\(Y\in L^2\)`라고 하자.

`\(\mathcal G\)`-가측인 `\(L^2\)` 확률변수 전체를


```math
L^2(\mathcal G) = \{W\in L^2:W\text{ is }\mathcal G\text{-measurable}\}
```


라고 하자.

6강에서는 이것이 닫힌 부분공간이라고만 말하고 넘어갔는데, 이유는 간단하다.

`\(L^2(\mathcal G)\)`는 확률공간 `\((\Omega,\mathcal G,P|_{\mathcal G})\)` 위의 `\(L^2\)` 공간 그 자체다.

6강의 Riesz–Fischer 정리는 어떤 확률공간에서나 성립하므로 이 공간도 완비이고, 완비인 부분공간은 닫혀 있다.


```math
\boxed{ L^2(\mathcal G)\text{는 }L^2(\mathcal F)\text{의 닫힌 부분공간이다.} }
```


따라서 6강의 사영 정리를 쓸 수 있다.

`\(Y\)`의 사영


```math
Z = \operatorname{Proj}_{L^2(\mathcal G)}Y
```


가 존재하고, 잔차 `\(Y-Z\)`는 `\(L^2(\mathcal G)\)`의 모든 원소와 직교한다.


```math
E[(Y-Z)W]=0 \qquad \forall W\in L^2(\mathcal G).
```


이 `\(Z\)`가 조건부 기댓값의 두 조건을 만족하는지 보자.

첫째, `\(Z\in L^2(\mathcal G)\)`이므로 `\(\mathcal G\)`-가측이다. 확률공간에서는 `\(L^2\subseteq L^1\)`(5강)이므로 적분가능하기도 하다.

둘째, `\(A\in\mathcal G\)`이면 `\(1_A\)`도 `\(\mathcal G\)`-가측이고 `\(E[1_A^2]=P(A)\le1\)`이므로 `\(1_A\in L^2(\mathcal G)\)`다.

따라서 `\(W=1_A\)`를 넣으면


```math
E[(Y-Z)1_A]=0, \qquad\text{즉}\qquad \int_A Z\,dP=\int_A Y\,dP.
```


두 조건을 모두 만족하므로 8절의 유일성에 의해


```math
\boxed{ E[Y\mid\mathcal G] = \operatorname{Proj}_{L^2(\mathcal G)}Y \qquad\text{a.s.} }
```


이다.

잔차 쪽에서 다시 쓰면


```math
\boxed{ Y-E[Y\mid\mathcal G] \perp L^2(\mathcal G). }
```


덤으로 두 가지를 얻는다.

하나는 `\(Y\in L^2\)`이면 `\(E[Y\mid\mathcal G]\)`도 `\(L^2\)`에 들어간다는 것이다. 사영은 `\(L^2(\mathcal G)\)` 안의 원소이기 때문이다.

다른 하나는 `\(Y\in L^2\)`일 때는 Radon–Nikodym 정리 없이 사영 정리만으로 조건부 기댓값의 존재가 나온다는 것이다. 7절과는 다른, 두 번째 존재 증명인 셈이다.

조건부 기댓값이 “최선의 예측”이 되는 이유가 여기 있다.

# 14. 회귀 = 조건부 기댓값 추정

이제


```math
\mathcal G=\sigma(X)
```


로 두자.

`\(\sigma(X)\)`-가측인 함수는 `\(g(X)\)` 꼴이므로


```math
\begin{aligned}
L^2(\sigma(X))
&= \{Z\in L^2 : Z\text{ is }\sigma(X)\text{-measurable}\} \\
&= \{g(X) : g\text{ is Borel measurable},\ E[g(X)^2]<\infty\}
\end{aligned}
```


는 `\(X\)`만 사용해 만들 수 있는 모든 square-integrable predictor의 공간이다.

조건부 기댓값은 `\(Y\)`를 이 공간에 사영한 것이므로


```math
\boxed{ E[Y\mid X] = \arg\min_{g(X)} E[(Y-g(X))^2]. }
```


이를 직접 확인해 보자.


```math
m(X)=E[Y\mid X]
```


라고 놓고 `\(E[g(X)^2]<\infty\)`인 임의의 predictor `\(g(X)\)`를 생각한다.

그러면


```math
Y-g(X) = (Y-m(X)) + (m(X)-g(X)).
```


제곱해서 기댓값을 취하면


```math
\begin{aligned}
E[(Y-g(X))^2]
&= E[(Y-m(X))^2]\\
&\quad+ E[(m(X)-g(X))^2]\\
&\quad+ 2E[(Y-m(X))(m(X)-g(X))].
\end{aligned}
```


그런데


```math
m(X)-g(X)
```


는 `\(\sigma(X)\)`-가측이고 `\(L^2\)`에 속하므로 `\(L^2(\sigma(X))\)`의 원소이며


```math
Y-m(X) \perp L^2(\sigma(X))
```


이므로 교차항은 `\(0\)`이다.

따라서


```math
\boxed{ E[(Y-g(X))^2] = E[(Y-E[Y\mid X])^2] + E[(E[Y\mid X]-g(X))^2]. }
```


두 번째 항은 항상 `\(0\)` 이상이므로 최솟값은


```math
g(X)=E[Y\mid X]
```


일 때 얻어진다.


```math
\boxed{ f^*(x)=E[Y\mid X=x]. }
```

# 15. 신경망이 직접 `\(E[Y\mid X]\)`가 되는 것은 아니다

여기서 머신러닝에서 자주 생기는 오해를 하나 구분하자.

population level에서 모든 가측함수 `\(g\)`를 허용한다면


```math
\arg\min_g E[(Y-g(X))^2] = E[Y\mid X].
```


하지만 실제 신경망 학습에서는


```math
g\in\mathcal H
```


라는 제한된 hypothesis class 안에서만 최적화한다.

그러면 실제 최적해는


```math
\boxed{ g_{\mathcal H}^* = \arg\min_{g\in\mathcal H} E[(Y-g(X))^2]. }
```


이다.

`\(\mathcal H\)`가 충분히 풍부하고 최적화와 데이터 문제가 잘 해결될 때에야 이것이 `\(E[Y\mid X]\)`에 가까워진다.

즉


```math
\boxed{ \text{conditional mean} \to \text{population target} \to \text{model-class approximation} \to \text{finite-data estimator} }
```


라는 여러 단계를 구분해야 한다.

선형회귀는 더 제한적이다.


```math
\mathcal H = \{a+bX\}
```


만 허용하므로 일반적으로


```math
a^*+b^*X \neq E[Y\mid X].
```


선형회귀는 `\(Y\)`를 `\(\operatorname{span}\{1,X\}\)`에 사영한 것이고, 조건부 기댓값은 훨씬 큰 공간 `\(L^2(\sigma(X))\)`에 사영한 것이다.

6강에서 본 선형회귀가 여기서 더 큰 그림 안에 들어간다.

# 16. irreducible error도 사영으로 보인다

앞의 분해


```math
E[(Y-g(X))^2] = E[(Y-m(X))^2] + E[(m(X)-g(X))^2]
```


에서


```math
m(X)=E[Y\mid X]
```


였다.

첫 번째 항


```math
E[(Y-E[Y\mid X])^2]
```


은 `\(X\)`를 아무리 잘 사용해도 없앨 수 없는 오차, 곧 irreducible error다.

이 오차를 `\(X\)`의 값별로 나누어 보자.

`\(Y\in L^2\)`일 때 조건부분산을


```math
\boxed{ \operatorname{Var}(Y\mid X) := E\big[(Y-E[Y\mid X])^2 \,\big|\, X\big] }
```


로 정의한다.

`\(X\)`가 주어졌을 때 `\(Y\)`가 조건부 평균 주위에서 얼마나 흩어져 있는지를 재는 양이다.

`\(E[Y\mid X]\)`와 마찬가지로 이것은 숫자가 아니라 `\(\sigma(X)\)`-가측인 확률변수다.

반면 irreducible error는 하나의 숫자다.

둘을 잇는 것은 6절에서 `\(A=\Omega\)`를 넣어 얻은


```math
E[E[Z\mid\mathcal G]] = E[Z]
```


이다.

13절에서 본 대로 `\(Y\in L^2\)`이면 `\(E[Y\mid X]\in L^2\)`이므로 `\(Z=(Y-E[Y\mid X])^2\)`는 적분가능하고, 여기에 `\(\mathcal G=\sigma(X)\)`로 적용하면


```math
E[(Y-E[Y\mid X])^2] = E\big[E[(Y-E[Y\mid X])^2\mid X]\big] = E[\operatorname{Var}(Y\mid X)].
```


`\(X\)`의 값마다 남는 조건부분산을 전체에 대해 다시 평균내면 irreducible error가 된다.

이제 앞의 분해로 돌아가 세 항에 이름을 붙이자.

좌변 `\(E[(Y-g(X))^2]\)`는 predictor `\(g(X)\)`의 prediction error다.

첫 번째 항은 방금 본 irreducible error이고, `\(g\)`를 어떻게 골라도 바뀌지 않는다.

두 번째 항 `\(E[(E[Y\mid X]-g(X))^2]\)`는 `\(g(X)\)`가 조건부 평균에서 얼마나 떨어져 있는지를 잰다.

`\(g\)`를 바꾸면 줄일 수 있으므로 reducible error라고 부른다.

따라서


```math
\boxed{ \underbrace{E[(Y-g(X))^2]}_{\text{prediction error}} = \underbrace{E[\operatorname{Var}(Y\mid X)]}_{\text{irreducible error}} + \underbrace{E[(E[Y\mid X]-g(X))^2]}_{\text{reducible error}}. }
```


15절의 구분을 여기에 겹쳐 보면 reducible error 안에도 여러 원인이 섞여 있다.

`\(g\)`가 `\(\mathcal H\)` 안의 최적해 `\(g_{\mathcal H}^*\)`라면 이 항은 모델 클래스의 한계에서 오는 approximation error다.

유한한 데이터로 학습한 `\(\hat g\)`라면 여기에 estimation error까지 함께 들어 있다.

# 17. Tower property — 정보를 두 번 평균내기

부분 `\(\sigma\)`-대수들이


```math
\mathcal H\subseteq\mathcal G\subseteq\mathcal F
```


라고 하자.

즉 `\(\mathcal G\)`가 `\(\mathcal H\)`보다 더 많은 정보를 가지고 있다.

그러면


```math
\boxed{ E[E[Y\mid\mathcal G]\mid\mathcal H] = E[Y\mid\mathcal H]. }
```


이것을 tower property 또는 law of iterated expectations라고 한다.

직관은 간단하다.

먼저 더 많은 정보 `\(\mathcal G\)`를 이용해 평균낸 뒤, 다시 더 적은 정보 `\(\mathcal H\)`밖에 모르는 상태로 평균내면 처음부터 `\(\mathcal H\)`만 알고 평균낸 것과 같다.

증명도 정의의 두 조건만으로 끝난다.

`\(E[Y\mid\mathcal H]\)`가 “`\(E[Y\mid\mathcal G]\)`의 `\(\mathcal H\)`에 대한 조건부 기댓값”의 정의를 만족하는지 보면 된다.

`\(E[Y\mid\mathcal H]\)`는 `\(\mathcal H\)`-가측이고 적분가능하므로 첫 번째 조건은 성립한다.

두 번째 조건을 보자. `\(A\in\mathcal H\)`라 하면 `\(\mathcal H\subseteq\mathcal G\)`이므로 `\(A\in\mathcal G\)`이기도 하다. 따라서


```math
\int_A E[Y\mid\mathcal G]\,dP \overset{A\in\mathcal G}{=} \int_A Y\,dP \overset{A\in\mathcal H}{=} \int_A E[Y\mid\mathcal H]\,dP.
```


첫 번째 등호는 `\(E[Y\mid\mathcal G]\)`의 정의이고, 두 번째 등호는 `\(E[Y\mid\mathcal H]\)`의 정의다.

8절의 유일성에 의해 `\(E[E[Y\mid\mathcal G]\mid\mathcal H]=E[Y\mid\mathcal H]\)` a.s.다.

`\(\mathcal H\subseteq\mathcal G\)`라는 가정은 `\(A\in\mathcal H\)`를 `\(\mathcal G\)`의 두 번째 조건에 넣을 수 있게 해 주는 데 쓰였다.

`\(Y\in L^2\)`라면 13절의 그림으로도 볼 수 있다. `\(L^2(\mathcal H)\subseteq L^2(\mathcal G)\)`이므로, 큰 부분공간에 먼저 사영한 뒤 작은 부분공간에 다시 사영하는 것은 처음부터 작은 부분공간에 사영하는 것과 같다.

특히 `\(\mathcal H=\{\varnothing,\Omega\}\)`이면


```math
\boxed{ E[E[Y\mid\mathcal G]] = E[Y]. }
```


이다.

변수로 쓰면 익숙한


```math
\boxed{ E[E[Y\mid X]]=E[Y]. }
```


가 나온다.

---

# 18. Bellman equation 뒤에도 tower property가 있다

강화학습에서 policy `\(\pi\)` 아래의 return을


```math
G_t = R_t+\gamma R_{t+1}+\gamma^2R_{t+2}+\cdots
```


라고 하자. 여기서 `\(G_t\)`는 return을 나타내는 강화학습의 관례적인 기호로, `\(\sigma\)`-대수 `\(\mathcal G\)`나 9절의 원자 `\(G_i\)`와는 관계가 없다.

state value는


```math
V^\pi(s) = E[G_t\mid S_t=s].
```


MDP와 policy `\(\pi\)`가 시간에 따라 변하지 않는다고 가정하므로 이 값은 `\(t\)`에 의존하지 않는다. 뒤에서 `\(E[G_{t+1}\mid S_{t+1}]=V^\pi(S_{t+1})\)`로 같은 `\(V^\pi\)`를 쓸 수 있는 것도 이 가정 덕분이다.

그런데


```math
G_t = R_t+\gamma G_{t+1}
```


이므로


```math
V^\pi(S_t) = E[R_t+\gamma G_{t+1}\mid S_t].
```


먼저 `\(\sigma(S_t)\subseteq\sigma(S_t,S_{t+1})\)`이므로 tower property에 의해


```math
E[G_{t+1}\mid S_t] = E[ E[G_{t+1}\mid S_t,S_{t+1}] \mid S_t ].
```


그리고 Markov property를 이용하면 미래에 필요한 정보가 `\(S_{t+1}\)`로 압축되므로


```math
E[G_{t+1}\mid S_t,S_{t+1}] = E[G_{t+1}\mid S_{t+1}].
```


따라서


```math
E[G_{t+1}\mid S_t] = E[ E[G_{t+1}\mid S_{t+1}] \mid S_t ].
```


여기에


```math
E[G_{t+1}\mid S_{t+1}] = V^\pi(S_{t+1})
```


를 넣으면


```math
E[G_{t+1}\mid S_t] = E[ V^\pi(S_{t+1}) \mid S_t ].
```


따라서


```math
\boxed{ V^\pi(S_t) = E[ R_t+\gamma V^\pi(S_{t+1}) \mid S_t ]. }
```


익숙한 Bellman equation의 조건부 기댓값 구조가 나온다.

즉 Bellman recursion은 단순히 미래 보상을 “한 단계 떼어내는 트릭”이 아니다.

정보를 단계적으로 조건화하는 tower property가 수학적 배경에 있다.

# 19. Taking out what is known

`\(X\)`가 `\(\mathcal G\)`-가측이고 적절한 적분가능성 조건을 만족한다고 하자.

그러면


```math
\boxed{ E[XY\mid\mathcal G] = X\,E[Y\mid\mathcal G]. }
```


이를 taking out what is known이라고 한다.

`\(\mathcal G\)`의 관점에서 `\(X\)`는 이미 알고 있는 값이므로 조건부 평균 밖으로 꺼낼 수 있다는 뜻이다.

예를 들어


```math
E[g(X)Y\mid X] = g(X)E[Y\mid X].
```


이 성질은 회귀의 직교성을 증명할 때도 계속 나타난다.

---

# 20. 독립이면 조건화해도 아무 정보가 늘지 않는다

`\(Y\)`가 `\(\mathcal G\)`와 독립이면


```math
\boxed{ E[Y\mid\mathcal G] = E[Y] \qquad\text{a.s.} }
```


이다.

`\(\mathcal G\)`를 아무리 관찰해도 `\(Y\)`에 대한 정보가 추가되지 않기 때문이다.

이것도 정의에서 바로 확인된다.

상수 `\(E[Y]\)`는 어떤 `\(\sigma\)`-대수에 대해서도 가측이므로 첫 번째 조건은 성립한다.

`\(A\in\mathcal G\)`이면 `\(1_A\)`와 `\(Y\)`가 독립이므로 7강의 `\(E[XY]=E[X]E[Y]\)`에 의해


```math
\int_A Y\,dP = E[1_AY] = E[1_A]\,E[Y] = \int_A E[Y]\,dP.
```


두 번째 조건도 성립한다.

특히 `\(X\)`와 `\(Y\)`가 독립이면


```math
\boxed{ E[Y\mid X] = E[Y]. }
```


독립성을

> `\(X\)`를 알아도 `\(Y\)`에 대한 예측이 달라지지 않는다.

라고 읽을 수도 있는 셈이다.

주의할 점은 역은 일반적으로 성립하지 않는다는 것이다.


```math
E[Y\mid X]=E[Y]
```


는 conditional mean만 변하지 않는다는 뜻이지, `\(Y\)`의 조건부분포 전체가 변하지 않는다는 뜻은 아니다.

---

# 21. Conditional Jensen

`\(\varphi\)`가 convex이고 필요한 적분가능성 조건이 성립하면


```math
\boxed{ \varphi(E[Y\mid\mathcal G]) \le E[\varphi(Y)\mid\mathcal G] \qquad\text{a.s.} }
```


이다.

이것이 conditional Jensen inequality다.

`\(\varphi(y)=y^2\)`를 넣으면


```math
(E[Y\mid\mathcal G])^2 \le E[Y^2\mid\mathcal G].
```


양변에 다시 기댓값을 취하면


```math
E[(E[Y\mid\mathcal G])^2] \le E[Y^2].
```


즉 조건부 기댓값이라는 사영은 `\(L^2\)` norm을 증가시키지 않는다.


```math
\boxed{ \|E[Y\mid\mathcal G]\|_2 \le \|Y\|_2. }
```


기하학적으로도 직교사영이 벡터의 길이를 늘리지 않는다는 사실과 정확히 일치한다.

---

# 22. 분산 분해 — law of total variance

조건부 기댓값의 사영 구조에서 또 하나의 익숙한 공식이 바로 나온다.


```math
Y-E[Y]
```


를


```math
(Y-E[Y\mid X]) + (E[Y\mid X]-E[Y])
```


로 나누자.

두 항은 서로 직교한다. 두 번째 항 `\(E[Y\mid X]-E[Y]\)`는 `\(X\)`의 함수이므로 `\(L^2(\sigma(X))\)`에 속하고, 첫 번째 항 `\(Y-E[Y\mid X]\)`는 13절에서 본 대로 `\(L^2(\sigma(X))\)` 전체와 직교하기 때문이다.

따라서 피타고라스 정리에 의해


```math
\begin{aligned}
\operatorname{Var}(Y)
&= E[(Y-E[Y])^2]\\
&= E[(Y-E[Y\mid X])^2] + E[(E[Y\mid X]-E[Y])^2].
\end{aligned}
```


첫 번째 항은 16절에서 본 대로


```math
E[\operatorname{Var}(Y\mid X)]
```


이다.

두 번째 항은 `\(E[E[Y\mid X]]=E[Y]\)`이므로 확률변수 `\(E[Y\mid X]\)`의 분산


```math
\operatorname{Var}(E[Y\mid X])
```


이다.

따라서


```math
\boxed{ \operatorname{Var}(Y) = E[\operatorname{Var}(Y\mid X)] + \operatorname{Var}(E[Y\mid X]). }
```


즉 전체 변동은


```math
\boxed{ X\text{를 알고도 남는 변동} + X\text{로 설명되는 변동} }
```


으로 분해된다.

회귀에서 설명 가능한 variance와 noise variance를 나누는 구조가 이미 여기에 들어 있다.

---

# 23. 계산 규칙을 한 번에 정리하면

조건부 기댓값에서 자주 사용하는 규칙들은 다음과 같다.


```math
E[aX+bY\mid\mathcal G] = aE[X\mid\mathcal G] +bE[Y\mid\mathcal G].
```



```math
X\text{가 }\mathcal G\text{-가측} \quad\Longrightarrow\quad E[X\mid\mathcal G]=X.
```



```math
X\text{가 }\mathcal G\text{-가측} \quad\Longrightarrow\quad E[XY\mid\mathcal G] = X E[Y\mid\mathcal G].
```



```math
Y\perp\!\!\!\perp\mathcal G \quad\Longrightarrow\quad E[Y\mid\mathcal G]=E[Y].
```



```math
\mathcal H\subseteq\mathcal G \quad\Longrightarrow\quad E[E[Y\mid\mathcal G]\mid\mathcal H] = E[Y\mid\mathcal H].
```


그리고 convex `\(\varphi\)`에 대해


```math
\varphi(E[Y\mid\mathcal G]) \le E[\varphi(Y)\mid\mathcal G].
```


이 공식들을 따로 외우기보다


```math
\boxed{ E[Y\mid\mathcal G] = \mathcal G\text{가 아는 정보만 남긴 평균} }
```


이라고 생각하면 대부분의 방향을 예측할 수 있다.

# 24. 마무리

학부 확률론에서는 조건화를


```math
P(A\mid B) = \frac{P(A\cap B)}{P(B)}
```


라는 비율로 처음 만난다.

하지만 연속확률변수에서는


```math
P(X=x)=0
```


이므로 이 공식만으로는


```math
E[Y\mid X=x]
```


를 설명할 수 없다.

해결책은 조건화를 사건 하나가 아니라


```math
\boxed{\text{정보를 나타내는 }\sigma\text{-대수}}
```


에 대해 정의하는 것이다.

부분 `\(\sigma\)`-대수


```math
\mathcal G\subseteq\mathcal F
```


에 대해 `\(E[Y\mid\mathcal G]\)`는


```math
\boxed{ E[Y\mid\mathcal G]\text{가 }\mathcal G\text{-가측} }
```


이고


```math
\boxed{ \int_AE[Y\mid\mathcal G]\,dP = \int_A Y\,dP \qquad \forall A\in\mathcal G }
```


인 확률변수다.

첫 번째 조건은


```math
\text{현재 알고 있는 정보만 사용하라}
```


는 뜻이고,

두 번째 조건은


```math
\text{그 정보로 볼 수 있는 모든 집단에서 평균을 보존하라}
```


는 뜻이다.

그리고 이런 확률변수가 존재한다는 사실은 8강의 Radon–Nikodym 정리에서 나온다.


```math
\boxed{ \text{RN theorem} \longrightarrow \text{conditional expectation}. }
```


`\(Y\in L^2\)`라면 여기서 한 단계 더 나아갈 수 있다.


```math
\boxed{ E[Y\mid\mathcal G] = \operatorname{Proj}_{L^2(\mathcal G)}Y. }
```


특히


```math
\boxed{ E[Y\mid X] = \operatorname{Proj}_{L^2(\sigma(X))}Y }
```


이므로


```math
\boxed{ E[Y\mid X] = \arg\min_{g(X)} E[(Y-g(X))^2]. }
```


즉


```math
\boxed{ \text{회귀} = \text{조건부 기댓값 추정} = L^2\text{ 사영} }
```


이라는 하나의 그림이 완성된다.

같은 연산은 회귀에서 끝나지 않는다.

회귀, 조건부확률, Bellman recursion, 마팅게일은 서로 전혀 다른 개념처럼 보이지만 모두


```math
\boxed{ \text{정보 }\mathcal G\text{에 대해 평균낸다} }
```


는 동일한 연산에서 출발한다.

마지막으로 사건 `\(A\)`에 대해서는


```math
\boxed{ P(A\mid\mathcal G) = E[1_A\mid\mathcal G]. }
```


따라서 조건부확률 역시 조건부 기댓값 안에 포함된다.

하지만 12절에서 본 것처럼 이 정의는 고정된 사건 `\(A\)`마다 확률변수를 하나씩 줄 뿐, 각 `\(x\)`마다 `\(A\mapsto P(A\mid X=x)\)`가 하나의 확률측도가 된다는 보장은 없다.

즉 필요한 것은


```math
\boxed{ \text{사건마다 따로 정의된 conditional probability} \quad\longrightarrow\quad \text{점마다 하나의 probability measure}. }
```


다음 강에서 이 역할을 하는


```math
\boxed{ K(x,A) }
```


를 도입한다.

이것이 확률 커널이고, 공동분포를


```math
\text{marginal}\times\text{conditional kernel}
```


로 분해하는 disintegration으로 이어진다.

그리고 그 언어 위에서


```math
\boxed{ \text{Bayes theorem} = \text{kernel을 뒤집는 법} }
```


으로 다시 읽게 된다.

## 다음 강 미리보기 — 10강 확률 커널과 측도론적 베이즈 정리

다음 강에서는


```math
K(x,A)=P(Y\in A\mid X=x)
```


가 정확히 무엇인지부터 시작한다.

그 뒤


```math
\mu K, \qquad KL, \qquad \mu\otimes K
```


와 같은 커널 대수를 정의하고,


```math
\boxed{ P_{X,Y}(dx,dy) = P_X(dx)K(x,dy) }
```


라는 disintegration을 통해 공동분포를 주변분포와 조건부분포로 분해한다.

마지막으로 prior `\(\Pi\)`와 likelihood kernel `\(P_\theta\)`에 대해


```math
P_\theta\ll\mu, \qquad p(x\mid\theta) = \frac{dP_\theta}{d\mu}(x)
```


라 놓으면


```math
\boxed{ \Pi(d\theta\mid x) = \frac{ p(x\mid\theta)\Pi(d\theta) }{ \int p(x\mid\theta')\Pi(d\theta') } }
```


라는 측도론적 Bayes 정리가 어떻게 나오는지 살펴본다.

8강의 RN derivative,

9강의 conditional expectation,

10강의 probability kernel이 여기서 하나의 사슬로 연결된다.


```math
\boxed{ \text{RN derivative} \longrightarrow \text{conditional expectation} \longrightarrow \text{conditional distribution/kernel} \longrightarrow \text{Bayes}. }
```
