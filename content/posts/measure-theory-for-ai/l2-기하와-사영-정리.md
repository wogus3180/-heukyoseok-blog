> **한 줄 요약**: `\(L^2\)`는 내적공간이다. 우리가 익숙하게 쓰던 평균·분산·상관계수는 사실 이 공간의 길이와 각도였고, 회귀는 사영이다.

# 들어가는 말: 평균제곱오차를 최소화하는 수는 왜 평균인가?

확률변수 `\(Y\)` 하나가 있다고 하자.

`\(Y\)`를 숫자 하나 `\(a\)`로 예측해야 하고, 오차를 평균제곱오차


```math
E[(Y-a)^2]
```


로 측정한다고 하자.

가장 좋은 `\(a\)`는 무엇일까?

미분해도 금방 나온다.


```math
\begin{aligned} E[(Y-a)^2] &=E[(Y-E[Y]+E[Y]-a)^2]\\ &=E[(Y-E[Y])^2]+(E[Y]-a)^2 \end{aligned}
```


중간항은


```math
E[Y-E[Y]]=0
```


을 인수로 가지므로 사라진다. 따라서


```math
\boxed{ \operatorname*{argmin}_{a\in\mathbb R} E[(Y-a)^2] = E[Y] }
```


이다.

보통 여기까지는 고등학교 확률의 계산처럼 보인다.

하지만 이번 강이 끝나면 이 식을 전혀 다르게 읽게 된다.


```math
\boxed{ E[Y] = Y\text{를 상수들의 공간 위로 직교사영한 것} }
```


이다.

그리고 9강에서는 상수들의 공간을 더 큰 공간으로 바꾼다.


```math
\boxed{ E[Y\mid\mathcal G] = Y\text{를 }\mathcal G\text{-가측인 }L^2\text{ 확률변수들의 공간 위로 사영한 것} }
```


즉,


```math
\boxed{ \text{평균} \longrightarrow \text{조건부 평균} \longrightarrow \text{회귀} }
```


는 사실 기하학이다.

그 기하학이 일어나는 공간이 `\(L^2\)`다.

---

# 요약

이번 강의 흐름은 다음과 같다.

### 1. `\(L^2\)`는 내적공간이다

5강에서 `\(L^2\)`는 "`\(E[X^2]<\infty\)`인 확률변수들의 모임"이었다. 여기에


```math
\boxed{ \langle X,Y\rangle := E[XY] }
```


를 얹으면 내적공간이 된다. 이 정의가 유한한 값을 준다는 보장이 바로 Cauchy–Schwarz이고, `\(\langle X,X\rangle=0\Rightarrow X=0\)`은 `\(L^p\)`를 동치류로 정의해 둔 덕분에 성립한다.

---

### 2. 평균·분산·공분산·상관계수는 전부 기하량이다


```math
\boxed{ \begin{aligned} E[X] &\leftrightarrow \text{상수 방향의 성분}\\ \operatorname{Var}(X) &= \|X-E[X]\|_2^2\\ \operatorname{Cov}(X,Y) &= \langle X-E[X],\,Y-E[Y]\rangle\\ \operatorname{Corr}(X,Y) &= \cos\theta \end{aligned} }
```


상관계수가 `\([-1,1]\)`에 놓이는 이유도 여기서 나온다. 그것은 코사인이기 때문이다.

---

### 3. `\(L^p\)` 중 내적을 갖는 것은 `\(L^2\)`뿐이다

내적에서 나온 norm은 평행사변형 법칙


```math
\|X+Y\|^2+\|X-Y\|^2=2\|X\|^2+2\|Y\|^2
```


을 반드시 만족해야 하는데, `\(p\neq2\)`인 `\(L^p\)`는 이를 어긴다. 게다가 `\(L^2\)`는 이 내적에 대해 완비다. 즉 `\(L^2\)`는 **힐베르트 공간**이다.

---

### 4. 최소제곱은 사영이다

닫힌 부분공간 `\(M\subset L^2\)`에 대해 모든 `\(Y\in L^2\)`는 유일한 최적근사 `\(P_MY\in M\)`을 갖고, 잔차는 그 공간에 수직이다.


```math
\boxed{ Y-P_MY\perp M }
```


허용하는 predictor의 공간을 넓혀 가면 같은 정리가 세 개의 익숙한 대상을 낳는다.


```math
\boxed{ \begin{array}{ccc} M\ (\text{허용 predictor 공간}) & & P_MY\ (\text{최적 MSE predictor})\\[3pt] \{a:a\in\mathbb R\} && E[Y]\\ \operatorname{span}\{1,X_1,\dots,X_d\} && \text{linear regression}\\ L^2(\mathcal G) && E[Y\mid\mathcal G] \end{array} }
```


마지막 줄이 9강 조건부 기댓값이다.

---

# 1. `\(L^2\)`에 내적을 넣는다

기하학을 하려면 먼저 무대가 있어야 한다.

5강에서 `\(L^2\)`를 정의했지만, 그때 얻은 것은


```math
L^2=\{X:E[X^2]<\infty\},\qquad \|X\|_2=\sqrt{E[X^2]}
```


즉 **집합 하나와 그 위의 크기 재는 법**뿐이었다.

여기에 구조를 하나 더 넣으면 이 집합이 기하학적 공간이 된다.

그 구조가 내적이다.

---

## `\(L^2\)`는 벡터공간이다

확률변수를 "벡터"라고 부르려면 먼저 더하고 상수배해도 공간 밖으로 나가지 않아야 한다.

`\(X,Y\in L^2\)`이고 `\(a,b\in\mathbb R\)`이라고 하자.

모든 실수 `\(u,v\)`에 대해


```math
(u+v)^2\le 2u^2+2v^2
```


이므로


```math
(aX+bY)^2\le 2a^2X^2+2b^2Y^2
```


이고, 양변에 기댓값을 취하면


```math
E[(aX+bY)^2]\le 2a^2E[X^2]+2b^2E[Y^2]<\infty.
```


따라서


```math
\boxed{ aX+bY\in L^2 }
```


이다.

즉 `\(L^2\)`는 실벡터공간이고, 이제 원소를 벡터라고 불러도 된다.

---

## 유한 표본공간에서 보면 그냥 `\(\mathbb R^n\)`이다

내적을 정의하기 전에, 5강에서 꺼냈던 `\(\mathbb R^n\)` 유비를 한 번만 더 보자.

`\(\Omega=\{\omega_1,\dots,\omega_n\}\)`이 유한하고 `\(p_i=P(\omega_i)\)`라고 하면, 확률변수는 좌표 `\(n\)`개짜리 벡터이고


```math
E[XY]=\sum_{i=1}^n p_i\,X(\omega_i)\,Y(\omega_i)
```


이다.

이것은 유클리드 내적 `\(\sum_i x_iy_i\)`에 **확률로 가중치를 준 것**이다.


```math
\boxed{ \langle X,Y\rangle=E[XY]\ \text{는 확률로 가중된 유클리드 내적이다.} }
```


`\(p_i\)`가 모두 `\(1/n\)`이면 `\(\frac1n\sum_i x_iy_i\)`가 되어, 상수배를 빼면 우리가 아는 그 내적 그대로다.

`\(\Omega\)`가 무한해지면 합이 적분으로 바뀔 뿐 구조는 같다. 앞으로 나올 모든 계산은 이 그림의 무한차원 버전이라고 생각하면 된다.

---

## 내적은 잘 정의되는가


```math
\langle X,Y\rangle := E[XY]
```


라고 쓰려면, 먼저 이 값이 **유한해야** 한다. `\(E[XY]\)`가 `\(\infty-\infty\)`가 되어버리면 정의 자체가 성립하지 않는다.

이것이 5강 Cauchy–Schwarz의 첫 번째 쓸모다.

`\(X,Y\in L^2\)`이면


```math
E[|XY|]\le\sqrt{E[X^2]}\sqrt{E[Y^2]}=\|X\|_2\|Y\|_2<\infty
```


이므로


```math
\boxed{ X,Y\in L^2 \implies XY\in L^1 }
```


이고, 따라서 `\(E[XY]\)`는 유한한 실수로 잘 정의된다.

지난 강에서 부등식을 먼저 다룬 이유가 여기서 드러난다. Cauchy–Schwarz가 없으면 내적을 **적을 수 없다.**

---

## 내적의 조건을 확인하자


```math
\boxed{ \langle X,Y\rangle := E[XY] }
```


가 실제로 내적인지 보자.

**대칭성 (symmetry)**


```math
\langle X,Y\rangle=E[XY]=E[YX]=\langle Y,X\rangle.
```


**쌍선형성 (bilinearity)**

기댓값이 선형이므로


```math
\langle aX_1+bX_2,\,Y\rangle=aE[X_1Y]+bE[X_2Y]=a\langle X_1,Y\rangle+b\langle X_2,Y\rangle.
```


**양정치성 (positive definiteness)**


```math
\langle X,X\rangle=E[X^2]\ge0
```


이고, 등호가 성립하면


```math
E[X^2]=0\quad\Longrightarrow\quad X=0\ \text{a.s.}
```


이다.

마지막 줄이 미묘하다. `\(X\)`는 함수로서 모든 점에서 `\(0\)`인 것이 아니라 **거의 확실하게** `\(0\)`일 뿐이다.

그런데 5강에서 `\(L^p\)`를 정의할 때 a.s. 같은 확률변수를 하나로 묶어 동치류의 공간으로 만들어 두었다.

그 덕분에


```math
X=0\ \text{a.s.} \quad\Longleftrightarrow\quad X=0\ \text{in }L^2
```


가 되어 양정치성이 성립한다.

5강의 그 처리가 없었다면 `\(\langle\cdot,\cdot\rangle\)`은 내적이 되지 못한다.

---

## 새 구조는 옛 구조와 일치한다

내적이 생겼으니 그 내적으로 길이를 재보면


```math
\sqrt{\langle X,X\rangle}=\sqrt{E[X^2]}=\|X\|_2
```


로 5강에서 정의한 `\(L^2\)` norm과 정확히 같다.

즉 새로 얹은 내적은 기존의 norm을 바꾸지 않고, 그 norm이 **어디서 왔는지**를 설명해 준다.

정리하면


```math
\boxed{ (L^2,\ \langle X,Y\rangle=E[XY])\ \text{는 내적공간이다.} }
```


이제 확률변수를 기하적으로 다룰 준비가 끝났다.

---

# 2. 평균·분산·공분산·상관계수는 기하량이다

무대가 준비됐으니 이제 익숙한 통계량들을 하나씩 이 공간의 언어로 옮겨 보자.

네 개가 전부 내적 하나에서 나온다.

---

## 평균은 상수 방향의 성분이다

상수확률변수 `\(1\)`을 생각하면


```math
\langle X,1\rangle = E[X].
```


또한


```math
\|1\|_2^2 = E[1]=1.
```


따라서 `\(1\)`은 길이가 `\(1\)`인 벡터이고


```math
E[X]1
```


은 `\(X\)`의 상수 방향 성분이다.

실제로


```math
X = E[X] + (X-E[X]).
```


첫 번째 항은 상수이고 두 번째 항은 상수 방향에 수직이다.

왜냐하면


```math
\left\langle X-E[X],1\right\rangle = E[X-E[X]] = 0.
```


따라서


```math
\boxed{ X = \underbrace{E[X]}_{\text{상수 방향}} + \underbrace{(X-E[X])}_{\text{상수 공간에 직교}} }
```


이다.

이것이 첫 문단에서 본


```math
E[X] = \operatorname*{argmin}_{a\in\mathbb R}E[(X-a)^2]
```


의 기하학적 이유다.



```math
\boxed{ \text{평균은 }X\text{의 상수공간 위 직교사영이다.} }
```


---

## 분산은 편차 벡터의 길이 제곱이다

분산의 정의는


```math
\operatorname{Var}(X) = E[(X-E[X])^2].
```


따라서


```math
\boxed{ \operatorname{Var}(X) = \|X-E[X]\|_2^2. }
```


즉 평균을 제거한 뒤 남은 벡터의 길이 제곱이다.

이 `\(X-E[X]\)`를 앞으로 **편차 벡터**(deviation vector)와 **중심화 벡터**(centered vector), 두 이름으로 부른다. 같은 대상이나 문맥에 따라 골라 쓰겠다.

이 관점에서


```math
E[X^2] = \operatorname{Var}(X)+(E[X])^2
```


는 Pythagoras 정리다.

실제로


```math
X=E[X]+(X-E[X])
```


이고 두 성분이 서로 직교하므로


```math
\boxed{ \|X\|_2^2 = \|E[X]\|_2^2 + \|X-E[X]\|_2^2. }
```


즉


```math
\boxed{ E[X^2] = (E[X])^2+\operatorname{Var}(X). }
```


익숙한 분산 공식이 사실 직각삼각형의 피타고라스 정리였던 셈이다.

---

## 공분산은 편차 벡터들의 내적이다

마찬가지로


```math
\operatorname{Cov}(X,Y) = E[(X-E[X])(Y-E[Y])]
```


이므로


```math
\boxed{ \operatorname{Cov}(X,Y) = \left\langle X-E[X], Y-E[Y] \right\rangle. }
```


따라서 두 확률변수의 공분산은 두 편차 벡터가 얼마나 같은 방향을 보는지를 측정한다.

---

## 상관계수는 cosine이다

`\(\operatorname{Var}(X),\operatorname{Var}(Y)>0\)`라고 하자.

상관계수는


```math
\rho_{X,Y} = \operatorname{Corr}(X,Y) = \frac{\operatorname{Cov}(X,Y)} {\sqrt{\operatorname{Var}(X)} \sqrt{\operatorname{Var}(Y)}}.
```


위의 `\(L^2\)` 표현을 넣으면


```math
\rho_{X,Y} = \frac{ \langle X-E[X],Y-E[Y]\rangle }{ \|X-E[X]\|_2 \|Y-E[Y]\|_2 }.
```


내적공간에서 두 벡터 사이의 각도 `\(\theta\)`는


```math
\cos\theta = \frac{\langle u,v\rangle}{\|u\|\|v\|}
```


로 정의하므로


```math
\boxed{ \rho_{X,Y} = \cos\theta. }
```


따라서 Cauchy–Schwarz로 즉시


```math
\boxed{ |\rho_{X,Y}|\le1 }
```


을 얻는다.

등호 조건도 그대로 따라온다. 5강 Cauchy–Schwarz의 등호 조건에서 본 대로 C–S의 등호는 두 벡터가 선형종속일 때 성립하므로


```math
\boxed{ |\rho_{X,Y}|=1 \iff Y=aX+b\ \text{a.s.인 }a\neq0,\,b\text{가 존재한다} }
```


이다. 두 중심화 벡터가 평행하다는 뜻이고, `\(\cos\theta=\pm1\)` 즉 각도가 `\(0\)` 또는 `\(\pi\)`라는 것과 같은 말이다. 상관계수가 `\(\pm1\)`이라는 것은 두 확률변수가 완전한 선형관계에 있다는 뜻이다.

상관계수의 범위가 `\([-1,1]\)`이라는 사실은 별개의 확률론적 기적이 아니다.


```math
\boxed{ \text{상관계수는 }L^2\text{에서 두 중심화 벡터 사이의 cosine이다.} }
```


---

# 3. `\(L^2\)`가 특별한 이유 — 힐베르트 공간

1절에서 `\(L^2\)`에 내적을 넣었다.

그런데 이것은 `\(p=2\)`에서만 일어나는 일이다.

`\(L^p\)`는 모두 norm을 갖는다. 하지만 그 norm이 **내적에서 나오는** 것은 `\(L^2\)` 하나뿐이다.

---

## 왜 하필 `\(p=2\)`인가

norm이 어떤 내적에서 나왔다면, 즉 `\(\|X\|=\sqrt{\langle X,X\rangle}\)`이라면 전개만으로 다음이 강제된다.


```math
\boxed{ \|X+Y\|^2+\|X-Y\|^2 = 2\|X\|^2+2\|Y\|^2 }
```


이를 **평행사변형 법칙**이라 한다. 평행사변형의 두 대각선 길이의 제곱합이 네 변의 제곱합과 같다는 초등기하의 사실이다.

이것은 선택이 아니라 필요조건이다. 내적에서 나온 norm이라면 반드시 성립한다.

`\(L^2\)`에서는 성립한다.


```math
E[(X+Y)^2]+E[(X-Y)^2]=2E[X^2]+2E[Y^2]
```


는 좌변을 전개하면 `\(\pm2E[XY]\)`가 상쇄되어 바로 나온다.

`\(p\neq2\)`에서는 깨진다. `\(\Omega=\{\omega_1,\omega_2\}\)`, `\(P(\omega_1)=P(\omega_2)=\tfrac12\)`인 두 점 공간에서


```math
X=(2,0),\qquad Y=(0,2)
```


를 잡자. `\(p=1\)`이면


```math
\|X\|_1=\|Y\|_1=1,\qquad \|X+Y\|_1=\|X-Y\|_1=2
```


이므로


```math
\underbrace{4+4}_{=8}\ \neq\ \underbrace{2\cdot1+2\cdot1}_{=4}.
```


평행사변형 법칙이 깨졌으므로 `\(\|\cdot\|_1\)`은 **어떤 내적에서도 나올 수 없다.**

같은 예가 `\(p=\infty\)`도 잡는다. 5강에서 정의한 `\(\|X\|_\infty=\operatorname{ess\,sup}|X|\)`로 재면


```math
\|X\|_\infty=\|Y\|_\infty=\|X+Y\|_\infty=\|X-Y\|_\infty=2
```


이므로


```math
\underbrace{4+4}_{=8}\ \neq\ \underbrace{2\cdot4+2\cdot4}_{=16}
```


가 되어 여기서도 법칙이 깨진다.


```math
\boxed{ L^p\text{ 중 내적공간은 }p=2\text{ 뿐이다.} }
```


`\(L^p\)` 사슬에서 `\(L^2\)`만 따로 떼어 다루는 이유가 이것이다. 크기는 어디서든 잴 수 있지만, **각도는 `\(L^2\)`에서만 잴 수 있다.**

- Pythagoras

이라는 기하학적 언어를 그대로 사용할 수 있다.

그리고 중요한 statement만 가져가자.


```math
\boxed{ L^2\text{는 완비인 내적공간, 즉 Hilbert 공간이다.} }
```


완비성, Hilbert 공간이 무엇인지와 증명은 생략하고 그에 따라 생기는 결과에 집중하겠다.

# 4. 사영 정리

`\(H\)`가 Hilbert 공간이고 `\(M\subset H\)`가 닫힌 선형부분공간이라고 하자.

그러면 모든 `\(x\in H\)`에 대해


```math
\boxed{ \|x-m^\ast\| = \inf_{m\in M}\|x-m\| }
```


을 만족하는 유일한 `\(m^\ast\in M\)`가 존재한다.

즉 `\(x\)`와 가장 가까운 `\(M\)`의 원소가 항상 하나 존재한다.

이 `\(m^\ast\)`를 `\(x\)`의 `\(M\)` 위로의 **직교사영**(orthogonal projection)이라 하고


```math
m^\ast=P_Mx
```


라고 쓴다. 아래첨자 `\(M\)`은 어느 부분공간으로 사영하는지를 가리킨다.

그리고 최적점의 특징은


```math
\boxed{ x-P_Mx\perp M }
```


이다.

즉 사영하고 남은 잔차는 그 공간의 모든 방향과 직교한다.

유클리드 공간에서 평면 위 가장 가까운 점을 찾았을 때 잔차가 평면과 수직인 것과 같다.

차원이 무한일 뿐이다.

---

# 5. 평균은 가장 단순한 `\(L^2\)` 사영이다

다시 첫 문단으로 돌아가자.

`\(L^2\)` 안의 상수확률변수들의 공간을


```math
M=\{a:a\in\mathbb R\}
```


라고 하자. 1차원이므로 닫힌 부분공간이고, 따라서 4절의 사영 정리를 그대로 쓸 수 있다.

이 공간 위로 `\(Y\)`를 사영하는 문제는


```math
\min_{a\in\mathbb R} \|Y-a\|_2^2
```


이고, `\(L^2\)` norm을 풀어 쓰면


```math
\min_{a\in\mathbb R} E[(Y-a)^2].
```


사영 정리에 따르면 최적값 `\(a^\ast\)`의 잔차는 상수공간에 직교해야 한다.

상수공간은 `\(1\)`이 span하므로


```math
\langle Y-a^\ast,1\rangle=0.
```


즉


```math
E[Y-a^\ast]=0
```


이고


```math
\boxed{ a^\ast=E[Y]. }
```


따라서


```math
\boxed{ E[Y] = P_M Y, \qquad M=\{\text{constant random variables}\}. }
```


평균이 MSE를 최소화한다는 익숙한 사실이 Hilbert 공간의 사영 정리의 예였다.

---

# 6. 회귀는 사영이다

이제 상수 하나보다 조금 더 많은 정보를 사용해보자.

예를 들어 feature


```math
X_1,\dots,X_d
```


를 이용해 `\(Y\)`를


```math
a_0+a_1X_1+\cdots+a_dX_d
```


꼴로 예측한다고 하자.

이 함수들의 집합은 `\(L^2\)` 안의 선형부분공간


```math
M = \operatorname{span} \{1,X_1,\dots,X_d\}
```


를 이룬다. 유한차원이므로 닫혀 있어 사영 정리를 그대로 쓸 수 있다.

최소제곱 회귀는


```math
\min_{\hat Y\in M} E[(Y-\hat Y)^2]
```


를 푸는 것이다.

즉


```math
\boxed{ \text{least-squares regression} = Y\text{의 }M\text{ 위 직교사영} }
```


이다.

최적 예측값 `\(\hat Y\)`는


```math
Y-\hat Y\perp M
```


을 만족한다.

따라서 `\(M\)`을 이루는 `\(1,X_1,\dots,X_d\)` 각각과 직교하므로


```math
E[Y-\hat Y]=0,\qquad E[(Y-\hat Y)X_j]=0\quad(j=1,\dots,d)
```


이다.

---

## 9강에서는 무엇이 바뀌는가

여기서는 허용하는 predictor를


```math
a_0+a_1X_1+\cdots+a_dX_d
```


처럼 제한했다.

9강에서는 이 제한을 거의 없앤다.

어떤 정보 `\(\mathcal G\)`가 주어졌을 때, 그 정보만을 이용해 만들 수 있는 모든 `\(L^2\)` 확률변수를 모으면


```math
L^2(\mathcal G)
```


라는 닫힌 부분공간이 된다.

그리고 `\(Y\)`를 그 공간 위로 사영한 것이


```math
\boxed{ E[Y\mid\mathcal G] }
```


이다.

즉


```math
\boxed{ E[Y\mid\mathcal G] = \operatorname*{argmin}_{Z\in L^2(\mathcal G)} E[(Y-Z)^2]. }
```


이번 강에서는 이 식을 증명하지 않는다.

다만 구조만 기억하자.

`\(M\)`을 정하는 일이 곧 `\(Y\)`를 예측할 때 **어떤 형태의 예측기까지 허용할 것인가**를 정하는 일이다. 아래 표의 왼쪽이 그 `\(M\)`이고, 오른쪽이 그때 나오는 `\(P_MY\)`다.

| 허용 predictor 공간 `\(M\)`                      | 최적 MSE predictor `\(P_MY\)` | 무슨 뜻인가                                  |
| ---------------------------------------- | ----------------------- | --------------------------------------- |
| `\(\{a:a\in\mathbb R\}\)`                    | `\(E[Y]\)`                  | 숫자 하나로만 예측                              |
| `\(\operatorname{span}\{1,X_1,\dots,X_d\}\)` | linear regression       | `\(X_j\)`들의 1차 결합까지 허용                      |
| `\(L^2(\mathcal G)\)`                        | `\(E[Y\mid\mathcal G]\)`    | `\(\mathcal G\)`로 만들 수 있는 모든 함수 허용 (비선형 포함) |

핵심은 세 공간이 포개진다는 것이다.


```math
\boxed{ \{a:a\in\mathbb R\} \subset \operatorname{span}\{1,X_1,\dots,X_d\} \subset L^2(\mathcal G) }
```


단 `\(\mathcal G\supset\sigma(X_1,\dots,X_d)\)`일 때다. 상수(평균)는 `\(a_1=\cdots=a_d=0\)`인 특수한 선형 예측기이고, 선형 예측기는 `\(X\)`의 함수 중 특수한 것이다.

공간이 커질수록 후보가 많아지니 MSE는 단조 감소한다.


```math
E[(Y-E[Y])^2] \ \ge\ E[(Y-\hat Y_{\text{lin}})^2] \ \ge\ E[(Y-E[Y\mid\mathcal G])^2]
```

# 7. 이 강의의 내용이 앞으로 쓰이는 곳

이번 강에서 얻은 가장 중요한 그림은


```math
\boxed{ \langle X,Y\rangle=E[XY] }
```


이다.

이 하나로


```math
\boxed{ \begin{aligned} E[X] &\leftrightarrow \text{상수 방향의 성분}\\ \operatorname{Var}(X) &\leftrightarrow \text{편차 벡터의 길이}^2\\ \operatorname{Cov}(X,Y) &\leftrightarrow \text{편차 벡터의 내적}\\ \operatorname{Corr}(X,Y) &\leftrightarrow \cos\theta\\ \text{least squares} &\leftrightarrow \text{orthogonal projection} \end{aligned} }
```


가 된다.

그리고 9강에서


```math
\boxed{ \text{conditional expectation} = \text{orthogonal projection} }
```


으로 완성된다.

# 8. 마무리

5강에서는 적분가능성의 등급으로 `\(L^p\)`를 만들었다.

이번 강에서는 그중 `\(L^2\)`에 내적


```math
\boxed{ \langle X,Y\rangle=E[XY] }
```


을 넣었다. 그러자 평균·분산·공분산·상관계수가 갑자기 기하학으로 바뀌었다.


```math
\boxed{ \begin{aligned} \text{평균}&=\text{상수공간으로의 사영}\\ \text{분산}&=\text{편차 벡터의 길이}^2\\ \text{공분산}&=\text{내적}\\ \text{상관계수}&=\cos\theta \end{aligned} }
```


그리고 최소제곱 회귀 역시


```math
\boxed{ \text{회귀}=\text{사영} }
```


으로 읽을 수 있었다.

이제 한 가지가 남았다.

지금까지는 주로 확률변수 하나를 놓고 적분했다.

하지만 실제 데이터셋은


```math
X_1,X_2,\dots,X_n
```


처럼 여러 확률변수를 **같이** 뽑는다.

“같이 뽑는다”는 것은 수학적으로 무엇일까?

두 확률공간을 하나로 묶으려면 어떤 `\(\sigma\)`-대수와 어떤 측도를 써야 할까?

그리고


```math
\int\int f(x,y)\,dP_X(x)dP_Y(y)
```


에서 두 적분의 순서를 아무 때나 바꿔도 될까?

이 질문이 다음 강의 출발점이다.


```math
\boxed{ \text{확률변수 하나의 적분} \quad\longrightarrow\quad \text{여러 확률변수의 공동공간} }
```


다음: **곱측도와 독립성 — "iid로 뽑는다"는 문장의 정확한 의미**

> **한 줄 요약**: "iid로 뽑는다"는 문장의 정확한 의미는 곱측도이고, 이중적분의 순서 교환에는 조건이 붙는다.
